# G题同步 Buck Rev B：嘉立创 EDA 120×90 mm 首轮布局

本轮已生成嘉立创 EDA 专业版原生 `.eprj2` 工程副本，在 GitHub 原工程中新增独立的 **G题 RevB — 布局草稿** 板页，包含 7 页可编辑原理图、完整主板器件和网络关联、120×90 mm 双层 PCB 初始布局。原 GitHub 的第一版、第二版板页均保留作参考。

**状态：原理图转录与 PCB 元件布局草稿；尚未布线，不能用于制板。** 工程是脚本追加原生历史生成的，尚未在嘉立创 EDA 客户端打开/导入验证；未运行原生 ERC/DRC。当前 NC 为图形注记，本机 ERC 时应按软件要求补齐真正的禁连标记。

## 打开方式

1. 使用支持 `.eprj2` 本地工程的嘉立创 EDA **专业版**客户端打开工程；来源工程版本标记为 `3.2.149.88089769`，数据库版本 `25.10.31.1`。不适用于标准版直接打开。
2. 选择 **G题 RevB — 布局草稿**，查看 7 页原理图和 **G题 RevB 120x90 — 待布线** PCB。工程默认页已指向 Rev B 的第一页。
3. 从 PCB 的原理图关联/更新功能核对器件对应关系与飞线；如果版本提示转换，另存副本，不覆盖来源工程。
4. 核实下面的机械封装、散热和接口条件后再开始布线，并运行专业版原生 ERC/DRC。静态核对通过不代替这一步。

## 依据与修改影响

比较基准有两个：用户提供的《G题同步Buck完整原理图_RevB.pdf》，以及 GitHub 的 `t3357065474-cloud/STM32-Digital-Synchronous-Buck-Converter` 提交 `a5c32acfa9f8550082be7b09675cc463bbca0b5b`。

- **相对用户 PDF 的原理图影响：** 将 PDF 的网络、物理引脚、参数转为可编辑原理图；没有主动更改 PDF 的电路拓扑、阻容数值或引脚分配。附录提取出的 96 个主板器件、43 个网络、264 个已连接引脚全部匹配；14 个 NC 引脚未接网。7 页采用逐器件命名网络连接，同名网络跨页相连；并非 PDF 图形排版的原样复制。
- **相对 GitHub 的原理图影响：** 新增独立 Rev B 板页，驱动由 IR2104S/SOIC-8 改为 IR2104PbF/DIP-8；电感由 47μH 改为 220μH；替换为 PDF 的 INA240A1D/INA181A1DBV 三路采样、三处分流器、五路 ADC、LM393 正负过流/过压比较、74HC74/74HC08/74HC14/BAT54 锁存与复位链路，接口改为外接 STM32 的 J_CTL 2×8。原 GitHub 两个板页的设计对象保持不变。
- **器件/BOM/PCB 影响：** 新增 Rev B 的 96 项主板 BOM 和全部封装关联，PCB 板框为用户确认的 120×90 mm、两层。QH/QL 保留 IRF540N/TO-220 的器件类型；其余按 Rev B 选择通用封装并明确待确认项目。本轮包含物理封装假设，不能称为无硬件影响，不能直接沿用 GitHub BOM 采购。
- **仿真/模型/固件影响：** 本轮未修改已有 Multisim/ngspice 仿真或 STM32 固件，未执行动态电路仿真；原 GitHub 固件未适配本设计。网络一致性不能证明控制、保护时序、效率或实际硬件功能通过。

## 布局与尚待确认的封装

上侧为功率路径，中部为驱动和电流采样，下侧为 ADC、硬件保护与锁存；左侧外接辅助模块，右侧 J_CTL。当前只是初始摆放，功率热回路、栅极回路、Kelvin 取样、模拟回流和去耦位置仍需随实际封装进一步收紧，不作为最终布局验收。

| 器件 | 当前占位假设 | 必须核实 |
| --- | --- | --- |
| L1 | 直插 D18 mm、脚距 10 mm | 220μH；Isat≥3A、Irms≥1.5A、DCR≤0.15Ω，实际脚距/外形 |
| C1 / C3 | 直插 D12.5 mm、脚距 5 mm | 470μF/50V 与 470μF/35V 的直径、脚距、高度、纹波能力 |
| F1 | 5×20 保险丝座、脚距 22.5 mm、外形约 27×9 mm | 具体保险丝座尺寸、脚距、开盖操作空间与 2A 保险丝规格 |
| J1 / J2 | 5.08 mm 2P 端子 | 插线方向、配套端子、孔径与接线操作空间 |
| J_AUX12 / J_AUX5 | 2.54 mm 1×4 接口 | 外接模块接线；没有假定任何电源模块的固定孔位 |
| J_CTL | 2.54 mm 2×8 接口，奇数脚左列 | 连接器型号、键位、排线方向及核心板实际供电 |
| D_BOOT | UF4007 轴向，脚距 10.16 mm | 成型脚距与本地封装引脚：1=A、2=K |
| QH / QL | 通用 TO-220-3、2.54 mm 脚距 | 散热片外形、固定方式、各自漏极背板绝缘 |
| U5 / U9 | LM393 通用 SOIC-8 | 具体订货型号/后缀、原厂 land pattern |
| 其余通用 SMD 封装 | R/C0805、R/C1206、R2512、SOIC/SOT 等 | 对应原厂推荐焊盘与选定料号；未绑定未经核实的商城编号 |

0.1% 分压/参考电阻必须按 BOM 精度采购；分流器按 ≥1W 选型并采用 Kelvin 分支引线。C2/C4/C_BOOT 等 MLCC 需要检查直流偏压后的有效容量。保留 PDF 的电阻模拟负载使用边界，未新增真实电池防倒灌设计。
