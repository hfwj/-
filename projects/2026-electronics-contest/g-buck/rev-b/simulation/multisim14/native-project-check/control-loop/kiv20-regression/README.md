# Ki20：C版改善后的静态工况回归

用户提供的C版`OPEN_C_KIV20`本机100ms截图显示：15V外部空载启动峰值约10.4V，后续起伏逐渐衰减，60～100ms接近10V；对比B版的持续起伏明显改善。数值均按图估读，未取得精确波形或保存工程。该现象支持电压环积分增益影响先前动态，但不证明它是唯一根因，也不证明实际固件已实现此控制。

每项均比较60～100ms整段，不以一个末端点代替稳定区间。观察输入保险丝状态、启动过冲、输出波动和电流；尽量保留精确数值导出，有报错则保留完整报错。不把预计目标写成已测结果。

输出电流是RS_OUT之后总电流，包含2.2kΩ泄放支路，所以20Ω时总电流略大于0.5A；RL支路电流可另选I(RL)。C版原预选I(L1)用于排查，回归版改选I(RS_OUT)用于恒流验收，二者含义不同。

这些静态工况结果齐备后，仍需在**同一Ki20模型、F1接入**的版本下复测自动负载变化及瞬态电流峰值；旧Ki100的自动切换图不能自动算成Ki20的回归通过。实际采样、STM32固件、保护锁存、输入电源真实上电浪涌、显示和含辅助供电的整机效率仍未验证。

## 修改影响：比较基线为C版15V空载工程

- 原理图的测试元件值：仅按工况改变V1输入15/25V及外接RL=20Ω/8Ω/5Ω/1GΩ；所有连线、MOS、电感、电容、驱动、采样电阻、F1=2A接入及临时R1断开均保持。
- 实物器件/BOM/PCB：无需更换板上器件或改板；RL为外接测试负载条件。
- 仿真/模型：同一C版电压Ki=20、其余控制和器件模型不变；100ms、50ns和RELTOL=0.003等设置不变。仅测量选项改为VOUT/I(RS_OUT)，分析标签按工况区分。
- 与早期Ki100工况不同：这些新文件不能沿用早期工况的“已通过”结果。本轮C的Ki100→20变化影响控制模型，当前没有改变实际STM32固件。

新工况的结构核对、模型/控制/连接不变检查、输入负载读回及两种容器解码器检查见[构建记录](results/build_checks.json)。本环境未运行Windows Multisim，未重做新工况的100ms开关交叉求解，文件结构通过不等于工况结果通过。原C/A/B及早期七文件均保留。
