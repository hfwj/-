# C版：只降低电压外环积分增益的控制对照

B版截图与A版定性接近，因此准备控制灵敏度对照，避免继续只改变求解精度。截图不能独立核验B的设置，相关判断保留这一限制。最新C本机100ms截图已显示起伏明显衰减，60～100ms接近10V、启动峰值约10.4V；未取得精确数据，不能把该观察升级为所有工况已通过。

## 本机运行

下载[独立C版](../../../../../downloads/GBUCK_OPEN_DIAG_C_KIV20_100ms.ms14)，或[C版专用ZIP](../../../../../downloads/Multisim14_空载C版_Ki20对照_2026-10-24.zip)，用Multisim打开，运行100ms。VOUT/I(L1)已预选；活动分析标签为`OPEN_C_KIV20 CVCC_EQ + SOFT_START`，主图工程标题可能仍沿用源文件名。

与B对比60～100ms的电压最高/最低值、起伏周期及I(L1)变化。Ki降低也可能使收敛变慢，不能只看末端一个点或只看100ms图比以前平就判为稳定。若出现完整报错，保留报错，不再叠加修改其他参数。若可导出数值波形，优先保留CSV/文本；不要求重画电路。

- 若周期/振幅随Ki明显变化，支持电压环参与该动态，但不独立证明唯一根因。
- 若仍相近，继续核查电流环跟踪、轻载电流/占空比与死区/驱动模型；不能直接换功率器件。
- C仅是控制对照，不取代原先25V/15V、20Ω/8Ω/5Ω、自动切换和F1的回归验证；尚未证明原图固件、采样、保护、效率或整机通过。

## 修改影响（比较基线：B版100ms）

| 项目 | C版变化 |
|---|---|
| 原理图连线、引脚、元件值 | 不变 |
| 实物器件、BOM、PCB | 不变，无需更换 |
| 物理驱动/MOS等嵌入模型 | 不变 |
| 电压外环积分增益 | **100→20 A/(V·s)**；控制源V3的模型动态改变，不是真实固件修改 |
| 其他控制参数 | 电压Kp=0.4、电流Kp=0.04/Ki=50、限幅−0.15～1A、软启动、100kHzPWM均保持 |
| 求解设置 | 沿用B：100ms、最大步长50ns、RELTOL=0.003和其他原容差 |
| 保险丝 | 保持F1=2A接入、临时R1断开 |
| 显示 | 活动瞬态分析标签改成OPEN_C_KIV20便于辨认 |
| 原A/B工程与原7工况 | 保留，不覆盖 |

改变的是V3仿真模板中的`G_IV`电压误差积分系数，两份保存模板同步更新；抗饱和系数1000不改。反馈仍是理想采样。检查使用精确XML反向替换证明除两份该系数和分析标签外无其他变化，并经两种DCL解码器回读。记录：[C构建检查](results/C_build_checks.json)、[可读控制模型](GBUCK_CTRL_EQ_KIV20.lib)。

另做5ms ngspice模型语法/启动检查，结果见[短时检查](results/C_5ms_smoke.json)。它只覆盖启动早期，不验证100ms后段稳定；F1仍用固定1mΩ近似，不能替代本机熔断行为。当前没有重新执行上次超时的100ms交叉测试。Windows Multisim的C版15V空载截图已收到，见[C本机观察记录](results/C_native_feedback.json)；精确数值和保存工程未回传。下一步进行[同参数静态回归](../kiv20-regression/README.md)。
