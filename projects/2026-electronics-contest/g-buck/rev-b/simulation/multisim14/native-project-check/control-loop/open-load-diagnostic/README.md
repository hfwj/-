# 15V空载起伏：下一步A/B对照

比较基线：用户回传的15V空载工程，F1=2A已接入，临时R1断开。两份副本保持同一原理图、元件值、嵌入器件模型和理想控制模型，只改变分析设置。它们是诊断副本，尚未在本环境打开或运行Windows Multisim，不标为稳定性修复。

## 本机只需先做这组对照

1. 解压[专用ZIP](../../../../../downloads/Multisim14_空载起伏_AB对照_2026-10-24.zip)，分别打开A、B文件，不覆盖原工程。
2. A：100ms、最大步长50ns、RELTOL=0.01，其他沿用回传工程。预选V(vout)和I(L1)。与刚才100ms图应可对照；如果已有同设置的数值导出，可保留已有A结果，不必重复跑。
3. B：同为100ms、50ns，只有RELTOL从0.01收紧到0.003；电压环、电流环、100kHzPWM、负载/输入、F1和其他容差全部不变。
4. 比较60～100ms的VOUT最高/最低值和起伏周期，以及I(L1)的相应变化。尽量导出图示仪的数值数据，格式以本机支持的CSV或文本为准；截图只作辅助，不能用单个末端点代替完整区间。
5. 若B出现“Timestep too small”，保留完整错误，停止该项；不要继续盲目收紧或放宽容差，也不要据此判为硬件损坏。A文件和全部原工程保留。

## 如何用结果决定后续

- A/B起伏接近：在此次精度对照下变化不明显，下一阶段优先核查轻载电流环跟踪、占空比/死区及电压环限幅；不能单凭这个结果证明数值误差完全不存在。
- B起伏明显变化：数值设置敏感，先建立可信求解条件，再评估控制修改。变平也不能单独证明真实电路已经稳定。
- B无法收敛：本次对照没有完成，不作根因定论。保留A及报错用于定位驱动/MOS模型事件。

之后才在独立控制模型副本调整参数或轻载策略，并复测15V/25V恒压、空载、8Ω/5Ω恒流和自动切换。此次没有修改PI，也没有加入零电流关断：IR2104现有互补驱动下，仅把电流指令下限改为0，并不能保证反向电流消失；不能将其称为完整二极管模拟。
