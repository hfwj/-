# Ki20与F1接入：动态负载切换

比较基线：[25V/20Ω静态Ki20工程](../../../../../downloads/GBUCK_KIV20_CV25_20R_100ms.ms14)。已有Ki20六个静态工况的本机截图；现在验证同一控制器能否在负载变化时自动保持恒压或转入恒流。

## 本机180ms反馈已收到

最新图显示约10V/0.5A→8V/1A→5V/1A，活动标签匹配，支持自动恒压转恒流和恒流段负载变化响应。80ms附近电流峰值约1.2～1.3A，130ms附近约1.6A；均为按图估读，精确值/持续时间未确认。稳态约1A不能写成全过程瞬时≤1A。见[独立截图记录](results/data/native_user_feedback.json)。本次仅归档，不修改任何原生工程、原理图、实物器件/BOM/PCB或模型设置。

## 本机运行一次180ms

下载[原生动态工程](../../../../../downloads/GBUCK_KIV20_AUTO_20R_8R_5R_180ms.ms14)或[独立ZIP](../../../../../downloads/Multisim14_Ki20动态切换工况_2026-10-24.zip)。打开后直接运行，VOUT和I(RS_OUT)已选择；活动分析标签为`KIV20_AUTO_20R_8R_5R 180ms`。大标题可能沿用源工程缓存，以活动标签和当前打开文件识别。

| 时段 | 外接负载 | 预计响应（待测，非结果） | 建议观察窗口 |
|---|---|---|---|
| 0～80ms | 20Ω | 恒压约10V，输出约0.5A | 60～75ms |
| 80～80.1ms过渡，此后至130ms | 8Ω | 自动转入约1A恒流，输出约8V | 110～125ms |
| 130～130.1ms过渡，此后至180ms | 5Ω | 继续约1A恒流，输出约5V | 160～175ms |

每次过渡100us；整个过程不需手动调控制参数或负载。尽量保留完整数值波形，分别核查三个后段窗口及80ms、130ms附近电流峰值/持续时间，不把稳态约1A当成全过程瞬时≤1A。输出电容会在负载变小时释放能量；旧Ki100动态约1.6A峰值不能自动当成新Ki20的实测结果，也不能预先宣称已消除。若无法导出数值，先保留整段图和两个切换附近的放大图。有报错则保留完整报错。

## 修改影响

- 原理图/器件：所有连线、引脚、功率管、电感、电容、采样电阻、驱动及自举保持。F1仍2A接入，临时R1仍断开，无板上器件/BOM/PCB改动。
- 测试负载：RL的仿真模板从固定20Ω改为受控电导，依次0.05S/0.125S/0.2S（20Ω/8Ω/5Ω）。画布沿用RL符号，旧固定数值显示隐藏；这是外接负载测试模型，不是新增实物芯片。
- 控制模型：沿用C版电压Ki20，其余全部控制和器件模型保持，不改真实固件。
- 分析设置：100ms→180ms，最大步长50ns和RELTOL0.003等选项保持，分析标签更新。
- 原静态及早期Ki100文件全部保留。相对旧Ki100动态45ms/18ms和28ms切换，本文件另用Ki20、F1接入及80/130ms时刻，因此验证结果分别记录。

## 已验证的范围

构建完成后检查了全部元件连接/参数、控制模板、嵌入器件模型保持，读回180ms设置和输出选择，并用两个独立DCL解码器回读原生容器。见[构建检查](results/data/build_checks.json)。

另外从新原生文件提取RL模板，在固定10V的独立负载台架执行180ms ngspice求解，确认三段电导正确，见[负载台架记录](results/data/load_bench.json)。台架在8Ω/5Ω时得到1.25A/2A，是固定10V下的负载特性；该检查只验证负载模板，不验证Buck闭环的恒流或动态性能。整套Buck的用户本机180ms截图现已收到，功能与峰值观察分别记录，精确数值仍待导出；本环境未启动Windows Multisim，也未执行新的180ms全功率级开关交叉求解。

复现顺序：设置既有dclimplode依赖，运行本目录`build_dynamic.py`、`verify_load.py`、`build_dynamic.py --package-only`。即使动态功能符合预期，真实传感器/固件、保护、上电浪涌、显示和整机效率仍需分别验证。

下一步固定现有Ki20，先从本机图示仪导出VOUT和I(RS_OUT)的数值波形（CSV/文本以本机支持为准），或用游标读出切换峰值/持续时间。优先核查60～75ms、110～125ms、160～175ms三个窗口及80/130ms附近事件。当前无新的控制调参或硬件修改。

## 130ms事件的光标读数

用户光标截图读数如下（保留显示有效位数，不等同完整原始波形）：

| 光标 | 时间/ms | VOUT/V | I(RS_OUT)/A |
|---|---:|---:|---:|
| 1：切换前 | 129.2455 | 7.9652 | 0.9992767 |
| 2：峰顶附近 | 130.1377 | 7.8272 | 1.5690 |

光标2比1A目标高56.9%，至少已观测到该点的1.5690A；不能把它当成未经搜索的精确全局最大值。按已交付拓扑，`7.8272/5 + 7.8272/2200 = 1.5689978A`，与显示1.5690A一致，支持输出电压仍较高时流向5Ω负载及泄放支路的解释。仅调电感平均电流限值不能消除输出电容已有能量造成的瞬时负载电流。

显示Δt=892.2347us、ΔI=569.7172mA、ΔV=−138.0684mV；两点数值与差值由软件分别舍入，保留原显示。Δt是“切换前光标到峰顶附近光标”的间隔，**不是过流持续时间**。下一步如测连续超过1A的时长，应把光标分别放到同一尖峰上升越过1A和下降首次回到1A的位置；Δt只代表该连续区间，不能代替所有超限区间总时长。完整数据导出更适合处理开关纹波导致的多次穿越。
