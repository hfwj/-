## 原图功能与检查结果

- U2输入、U3输出：20倍增益、50mΩ分流器，对应名义1V/A。U4电感：20倍、25mΩ，中点为3V3_A/2，对应0.5V/A。
- 正过流：U5A的V+=VREF_POS，V−=IL_BI；反过流：U9A的V+=IL_BI，V−=VREF_NEG；过压U5B的V+=VREF_OV、V−=VOUT_DIV。三个开集输出汇合到FAULT_N，R13上拉到3.3V。
- 精确3.3V_A下标称门限±1.8A及11V。包含R_VDDA=10Ω和参考分压负载、但未加入真实芯片静态电流时，本模型约3.2975V_A，扫描得到正向触发1.799A、负向解除−1.798A（1mA网格），过压10.992V（1mV网格）。负向数字是升序扫描的解除边界，不混写为下降触发的精确值。
- 故障由U6异步清零，故障解除不自行恢复；只有新的ARM上升沿才置位。MCU_EN仅与SAFE_OK相与，普通MCU_EN拉低不清除SAFE_OK，重新拉高时若SAFE_OK仍在会恢复使能。这与“故障后必须重新ARM”是不同场景。
- 正过流比较器走原始IL_BI，独立ADC_IL的C由4.7nF放大到47nF的对照未使本模型原始保护路径延迟增加到ADC滤波时间。小幅过压的VOUT_DIV仍可能受分压器源阻抗和ADC支路电容负载影响，不能认为“在ADC RC之前取样”就完全无动态影响。
- 五路ADC的物理钳位连接已审查，VIN支路做了正负越界扫描；钳位使用定性二极管模型，不能据此认证MCU绝对最大额定值、钳位注入电流或所有支路实际误差。

## 已发现的限制和后续

1. **停机/重启控制状态有缺口。**基线重新ARM前的电流积分状态约0.198，随后电感电流约1.838A再次触发保护。积分累积参与的解释有数据支持；未完成验证的停机积分复位实验不作为“已修复”。真实固件还未提供。
2. **1A输出瞬态峰值不由该保护保证。**原图看电感电流、门限约±1.8A；此前输出端1.569A不等同电感同值，也未达到同一门限。不能简单把比较器改成1A就宣称解决输出电容放电峰值。
3. **模拟电源和公差影响门限。**另加5/10mA模拟供电负载的假设场景，正向网格触发变为约1.772/1.745A；这不是已知器件真实静态电流。假设3V3_A±5%并叠加BOM电阻误差的解析角点，过压边界可能约10.286～11.733V，说明需要实测供电和误差预算；±5%是研究假设，不是对未提供稳压模块的额定断言。
4. **F1不是1A输出限流或高速保护。**它是输入端2A保险丝。BOM未给出具体厂家时间电流/I²t曲线；本次不认证熔断时间，交叉求解仍将导通F1作为1mΩ，输入电源真实上电浪涌也未包含。
5. **有源时序是假设。**INA模型为G20/零偏/轨限、1us一阶响应和1Ω输出；比较器0.3us极点、1uV数值滞回、10Ω导通；HC14采用0.3/0.6供电比例阈值。模型内部RC、开关和二极管均不新增到BOM。不能把波形微秒数当作实物最大关断延迟或逐周期短路保护。
