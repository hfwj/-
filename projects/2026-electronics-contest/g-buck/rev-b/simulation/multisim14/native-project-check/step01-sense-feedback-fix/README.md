# 用户STEP01：采样接入后的反馈别名修正

比较基线为用户回传`GBUCK_STEP01_IL_SENSE.ms14.ms14`，完整保存在references/user-projects。U2/U4采样极性、供电、参考、去耦及NC接线均核对正确。

内部节点2/3仍在，但已分别被命名为L_RAW/V_CAP。主电路导出用别名，V3内部自定义模板仍写数字2/3，因而读不到实际电感差压。只修正调用：

- 原：`XCTRL %t1 %t2 VOUT 3 7 2 GBUCK_CTRL_EQ`
- 新：`XCTRL %t1 %t2 VOUT V_CAP 7 L_RAW GBUCK_CTRL_EQ`

[原生修正版](../../../../downloads/GBUCK_STEP01_IL_SENSE_FEEDBACK_FIX.ms14)，用户当前接线、模型、Ki20控制方程/参数、30ms及原始分析设置/输出选择全部保留。精确逆变换及两套DCL解码检查见[build_checks.json](results/data/build_checks.json)。

## 当前验证状态

- 原失配副本独立ngspice求解完整7ms：控制器内部电感读数为0，实际电感峰值约5.228A，复现反馈失效机制。
- 修正版50ns梯形法交叉求解到20.734ms，480s执行时限导致未完成30ms；该段电感峰值约1.077A，末点输出约9.504V，反馈随实际电感电流变化。这个时限不是收敛失败。
- Gear对照在4.920ms发生步长过小，未完成，记录保留；未将原生文件改为Gear。
- 200ns梯形法30ms独立复核正在进行，本段结果不得当作已经完成的30ms通过记录。
- Windows Multisim未在本环境运行。用户可先打开修正版、按保留的30ms设置重新运行，检查原4条曲线，并按需加V(VOUT)。

交叉求解将F1视为1mΩ导通电阻，没有热熔断/I²t；原生仍保留2A保险丝。故原失配副本数值不声称与用户截图逐点一致。本机若F1仍处于熔断状态，应先恢复正常状态再运行，额定值保持2A。
