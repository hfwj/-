## 端口区别

原模型定义：`.SUBCKT INA181A1 INP INN VCC GND REF OUT`。它虽为6端，顺序仍不等于实物物理脚号。

新增接口定义：`.SUBCKT INA181A1_TI_6PIN OUT GND INP INM REF VS`。接口只调用原子电路，不改增益/偏移/动态/静态电流或器件模型。

| 物理脚/适配模型端口序号 | 功能 | 对应原模型端口 | 原图U3连接 |
|---|---|---|---|
| 1 | OUT | 6 OUT | IOUT_RAW |
| 2 | GND | 4 GND | 公共地 |
| 3 | INP / IN+ | 1 INP | V_CAP |
| 4 | INM / IN− | 2 INN | VOUT |
| 5 | REF | 5 REF | 公共地 |
| 6 | VS | 3 VCC | +3V3_A |

模型原始定义共有17个子电路，适配层后面的原文件逐字节保留，包括混合CRLF/LF换行与版权。元器件向导应选择顶层`INA181A1_TI_6PIN`；内部的IQ、CMRR、ZOUT、COMPARATOR等不是可独立代替U3的器件。

- 41个点完整完成；适配层与原模型直接调用的输出差异在导出精度内为0V。
- 10～50mV差压间的增量增益约19.99743V/V。
- 25mV差压输出约0.497700V，零差压约19.985mV。零点受模型低端摆幅影响，不能要求恰为0V。

## 三颗芯片共用模拟电源的DC检查

单独测试U2/U3/U4及原图R_VDDA=10Ω、模拟电源去耦；不含主功率开关、比较器参考分压、ADC滤波和MCU负载。测试差压U2=10mV、U3/U4=25mV：

| 观察量 | 此DC测试结果 |
|---|---:|
| +3V3_A | 3.261418V |
| U2输出 | 0.199800V |
| U3输出 | 0.497691V |
| U4输出 | 2.130578V |
| 此测试台总供电电流 | 3.858248mA |

U4输出随实际模拟电源中点变化；两颗TI INA240及一颗TI INA181的模型有供电负载，不能继续把模拟电源当作精确3.3V。此表不是完整板上电流、效率或硬件预测，新增比较器参考/ADC/控制负载后需再计算。
