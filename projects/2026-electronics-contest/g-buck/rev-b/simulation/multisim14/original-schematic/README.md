# 按原始Rev B原理图在NI Multisim 14.0中逐元件绘制

本资料依据用户提供的10页原始原理图PDF及B3物料清单，供在Multisim中逐个放置器件、连线和核对。保留原图96个主板器件/接口/测试点的位号与连接，另说明控制板、辅助电源和测试负载的处理。

当前交付为绘图参考PDF/SVG和接线表；没有生成原生`.ms14`工程，也没有在Windows Multisim中操作或运行。图中IR2104、INA、LM393及HC芯片采用原图物理引脚标注，是否有可运行的仿真模型须在本机数据库核对。

- [元件数值与Multisim选择CSV](原图元件与Multisim选择.csv)：96项，各自的原值、所属页及选择方法。

- [逐网络连接CSV](逐网络连接表.csv)：43个网络的全部端点。

专用ZIP内的原PDF在`references/`中；仓库中原件在项目`references/`中。原PDF第9～10页的网络附录是本次接线表的来源。不要将原PDF中的既往仿真描述视为本次Multisim运行证据。

## 图上的网络怎样变成Multisim连线

图纸各页沿用原网络名，例如`VIN_EXT`、`VIN`、`SW`、`V_CAP`、`VOUT`、`G_H`。同名端点在电气上必须连在一起。

首次建议在同一张Multisim图纸上分区绘制：先用实际导线连接一个模块，再用软件的同页连接器连接同名网络。跨页时使用相应跨页连接器并核对作用范围，不能只放一段文字。连接器菜单通常位于`Place → Connectors`，具体翻译以本机为准。

每个网络至少检查一次连通高亮或生成的网表。尤其要保持`+3V3`与`+3V3_A`为两个不同网络，由R_VDDA连接；`VIN_EXT`与`VIN`之间仍有保险丝、D1和分流器。

`GND`统一连接SPICE全局地0；单纯写出GND字样不建立参考地。标为`NC`的引脚悬空，不能把所有NC脚合成一个网络。

## 1. 新建工程与选择元件

1. 新建空白设计，先另存为`G_Buck_RevB_original.ms14`。该文件由本机Multisim保存生成。
2. 通过`Place → Component`放置基础电阻、电容、电感、二极管、MOS和IC。先按CSV搜索型号；组、族名称随安装数据库不同，不预设所有电脑都能搜索到IR2104或INA240。
3. 基础阻容可用带模型的通用器件，改数值及位号。若软件不允许直接用`RS_IN`等位号，保留软件合法位号，并添加原位号标签和对应记录。
4. MOS按G/D/S名称连接。原图TO-220是1=G、2=D、3=S；本机符号编号和导入SPICE模型端口顺序可能不同，不能仅按“第一个端口”连接。
5. IC若拆成A/B等多个单元，必须使用同一封装内对应单元，并放置或检查电源单元。LM393两个通道的电源为同一组8脚/4脚。
6. 元件有符号不代表有仿真模型。缺模型的器件先标注“模型待补”，不要用引脚数相同的芯片代替。

优先查找IRF540N/IRF540、IR2104、INA240A1、INA181A1、LM393、74HC74、74HC08、74HC14。IRF540近似替换IRF540N时须记录，不能据此核验原型号损耗。HC系列应核对3.3V供电及模拟/数字接口模型；74LS系列的供电和逻辑阈值不同，不能直接替换。

若IR2104等没有模型，需要另行导入相符的可用模型，或建立明确注明范围的单芯片功能模型；此资料包未附厂家模型。此前17脚GBUCK_REVB_EQ模型封装了整个功率级和控制网络，不用它占据原图中某一颗芯片的位置。

## 2. 先画第1页主功率级

按图从左向右连接：

```text
VIN_EXT → F1 → FUSED → D1 → V_SHUNT_IN → RS_IN → VIN
VIN → QH漏极；QH源极 → SW；QL漏极 → SW；QL源极 → GND
SW → L1 → L_RAW → RS_L → V_CAP → RS_OUT → VOUT
```

关键值和分支：

| 器件 | 值与连接 |
|---|---|
| F1 | 2A保险丝；原图F1.1=VIN_EXT、F1.2=FUSED |
| D1 | SS56；原图物理2脚A=FUSED、1脚K=V_SHUNT_IN |
| RS_IN | 0.05Ω，V_SHUNT_IN到VIN |
| C1、C2 | 470μF、1μF，均跨VIN与GND |
| QH、QL | IRF540N，上管G=G_H，下管G=G_L |
| L1 | 220μH，SW到L_RAW |
| RS_L | 0.025Ω，L_RAW到V_CAP，在输出电容之前 |
| C3、C4 | 470μF、10μF，均跨V_CAP与GND |
| RS_OUT | 0.05Ω，V_CAP到VOUT，在输出电容之后 |
| R_BL | 2.2kΩ，VOUT到GND |
| 外接负载RL | 首次用20Ω，VOUT到GND；另测试8Ω/5Ω |

注意输入值单位：分流器是`0.05Ω`和`0.025Ω`，不是50Ω/25Ω。Multisim数值框若不接受`m`后缀，直接填十进制数及Ω单位。

原图没有单独的R_L_DCR、R_C3_ESR或4.7nF栅极电容。需要加入寄生参数时，在元件属性中设置或另加带`SIM_`标记的元件，并记录来源，避免内部电阻与外接电阻重复计入。原L1的DCR要求≤0.15Ω，不代表实测值已知。

## 3. 画第2页IR2104驱动

| 原图物理脚 | IR2104功能 | 接到 |
|---|---|---|
| 1 | VCC | +12V_DRV |
| 2 | IN | PWM_IN |
| 3 | /SD | DRV_EN |
| 4 | COM | GND |
| 5 | LO | RG_L的一端；RG_L另一端G_L |
| 6 | VS | SW |
| 7 | HO | RG_H的一端；RG_H另一端G_H |
| 8 | VB | 自举节点VB |

RG_H、RG_L各10Ω；R_GSH=10kΩ跨G_H与SW，R_GSL=10kΩ跨G_L与GND。D_BOOT的A接+12V_DRV、K接VB；C_BOOT=1μF接VB与SW，不能接VB与公共地。

PWM_CTL经R_PWM=100Ω接PWM_IN；PWM_IN经10kΩ下拉；DRV_EN经100kΩ下拉。C5=100nF、C6=10μF跨驱动12V与地。

停止时令DRV_EN低，关闭两路。IN低且驱动有效时低侧可能导通，不能将“PWM低”当作两管均关闭。

## 4. 画第3～5页采样、ADC和保护

按逐引脚CSV接U2、U3、U4。正向电流的IN+、IN-分别是：U2=V_SHUNT_IN/VIN；U3=V_CAP/VOUT；U4=L_RAW/V_CAP。U4双参考脚分别接+3V3_A与GND；U2两个参考脚均接GND；NC脚保留悬空。

两路电压分压均为11:1，但阻值不同：输入100kΩ/10kΩ，输出10kΩ/1kΩ。五路ADC分别有1kΩ串联、4.7nF对地及独立BAT54S钳位。BAT54S的物理1脚接GND、2脚接+3V3、3脚接ADC节点；拆成两只二极管时按图中的A/K关系连接。

U5、U9为LM393：8脚+5V、4脚GND。U5的1/7脚与U9的1脚接FAULT_N，由R13=10kΩ上拉至+3V3。不能改用推挽输出比较器后仍把多个输出直接并联。

分压参考链按图逐项连接，不能用一只等值电阻取代而丢掉网络标识。标称模拟电源3.3V时，正/负电感阈值为2.55V/0.75V，过压参考1.00V，对应输出约11V。应在本机仿真中先量这三个参考电压。

## 5. 画第6页复位、锁存、使能

按原图物理引脚表放置HC74、HC08、HC14及其电源。若软件隐藏了电源脚，确认实际绑定的是3.3V和GND；不能仅放一个写着3.3V的文字标签就认为供电已更改。

U6第一路D固定高，ARM接时钟，FAULT_N接异步清零，Q输出SAFE_OK；U7第一路将SAFE_OK与MCU_EN相与，输出DRV_EN。U8两级施密特反相配合R14/C11和D_POR构成上电清零。

所有备用输入按原图固定高低电平，备用输出保持NC。D_POR物理1脚A接FAULT_N、3脚K接POR_OK、2脚NC。

## 6. 处理控制板与辅助电源

J_CTL按第7页保留连接。STM32F103、LCD、按键的存在不自动构成可执行固件仿真；目前没有提供固件或适配本机的处理器仿真模型。

先做分块测试时，可用独立测试电源提供12V、5V和3.3V，并用测试信号暂代控制板输出。每个电源正端接对应网络，负端接GND；同一电源轨不并接两个不同的理想电源。它们属于测试夹具，不能作为M1/M2真实效率验证。

辅助电源替代时可使用从0V缓升到目标值的PWL源，例如3.3V轨为`PWL(0 0 0.5m 0 1m 3.3)`，12V和5V轨同样处理。具体源的参数入口以本机界面为准。

## 7. 首轮调试先验证连线与驱动

1. 先给采样/逻辑/驱动电源，PWM_CTL=0、MCU_EN=0、ARM=0；检查FAULT_N在POR结束后为高，SAFE_OK保持低。
2. 只有模型完整且参考电压正常后，再连接25V输入和20Ω负载。
3. 以5ms开始、幅度3.3V、宽10μs的ARM脉冲置位；5.1ms后MCU_EN变高，让低侧预充自举电容。
4. 从5.2ms开始给100kHz、约10%占空比的PWM，先观察两管栅源电压与SW。频率和时序均为本次建议的测试条件，不是原PDF提供的固件参数。
5. 可用`PULSE(0 3.3 5.2m 20n 20n 1u 10u)`生成上述PWM；ARM可用`PULSE(0 3.3 5m 20n 20n 10u 1)`。MCU_EN可用`PWL(0 0 5.1m 0 5.101m 3.3)`。这些测试信号应接在断开的控制板输出位置。
6. 上管测`V(G_H)-V(SW)`，下管测`V(G_L)`；C_BOOT测`V(VB)-V(SW)`。不要把上管G_H对地电压当成VGS。
7. 瞬态先观察0～10ms，最大步长建议100ns，使用适合各模型的零初始条件；若数字模型另有初始化要求，应按其说明设置。未提供本机运行通过记录。

这轮低占空比测试用于核对连线、使能和自举，不要求输出10V。直接以约40%固定占空比启动可能发生过冲并触发保护；达到10V/1A自动CV/CC需要软启动和反馈控制，不能通过手动换占空比冒充。此前连续控制模型的结果也不能视为当前逐芯片图和实际固件已通过。

## 8. 分阶段保存本机文件

建议在本机依次保存：`01_power.ms14`、`02_driver.ms14`、`03_sense_protect.ms14`、`04_control_complete.ms14`。每次只增加一个模块，检查电源、网络连通、模型和波形后再继续。完整图画完后，还需按题目测试15～25V输入、空载/20Ω恒压、8Ω/5Ω恒流、保护和整机效率。

## 生成和核对

维护者在本目录运行`python build_original_drawing.py`。脚本从原PDF第9～10页提取43个网络，核对96个器件和全部物理引脚，生成图纸、CSV、JSON和专用ZIP。原PDF不修改。

此核对验证资料转录及覆盖关系，不是Multisim电气规则检查、模型兼容性或仿真通过记录，也不建立实物效率、热或固件正确性的结论。
