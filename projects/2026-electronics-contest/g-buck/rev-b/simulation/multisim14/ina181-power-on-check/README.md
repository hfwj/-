## 本次结果

ngspice44.2、PSpice兼容模式、梯形法、最大步长10ns；两组采用相同负载100kΩ及相同求解选项，包括1TΩ全局rshunt。

- 有序上电：VS在1～11us由0升至3.3V；输入共模在15～25us由0升至10V；35～35.01us差分输入由0升至25mV。完整100us、10124点，无报错。30us零差分时输出约19.908mV，末点约497.244mV（接近标称500mV）。零差分附近存在输出下限，因此不能用0→25mV两点的割线当作线性区增益精度。
- 固定电源对照：VS=3.3V、共模=10V从初始即存在，其余相同；约0.264ns时报步长过小，未完成100us。进程返回0不能掩盖日志中失败。

这支持初始化条件会影响当前模型的收敛；只验证了上述特定激励，不保证任意上电顺序、Buck接入或Windows Multisim动态通过。本环境没有运行Windows Multisim。此前DC扫描结果与这些动态结果分别记录。
