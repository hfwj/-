# Multisim逐芯片接线：电流采样功能模型

后续用户已上传INA240A1的TI PSpice模型，U2/U4优先按[厂商模型端口适配说明](../ina240a1-ti-import/README.md)导入；本目录_FUNC保留作功能对照。U3的INA181厂商模型尚未收到。本目录的功能检查不能等同新TI模型或整机已通过。

2026-10-24。用户本机截图：主数据库、所有组、所有系列搜索INA240，无结果。云端尝试访问TI产品页被网络代理以403拒绝，未下载到厂商模型。

本目录提供自行编写的**单芯片功能等效模型**，让U2、U3、U4能分别放到主图上接线。每个文件仅含一个顶层.SUBCKT，不包含功率级、比较器、锁存器或PWM控制，也不自动接入现有工程。

这不是TI模型，不是INA芯片真实精度、共模范围、PWM干扰抑制或时序验证。原图实物型号仍为INA240A1D/INA181A1DBV，仿真元件明确命名为带`_FUNC`的模型，避免混淆。

## 当前只做到向导入口

1. 下载并解压[模型包](../../../downloads/Multisim14_Sense_Chip_Functional_2026-10-24.zip)，模型文件位于包内`models/`。建议放到本机纯英文路径，例如`D:\MultisimModels\Sense`。
2. 关闭当前的“选择一个元器件”窗口。
3. 打开“工具→元器件向导”。具体中文名称和页次以本机界面为准。
4. 首先创建`INA240A1_FUNC`，目标是仿真元件。若有“仅仿真/Simulation only”选项，选择它；本步骤不创建或分配真实PCB封装。
5. 将向导当前页面截图发回，再逐页核对符号、模型导入和引脚映射。尚未在Windows Multisim执行，不能声称已完成本机导入。

后续模型页选择`models/INA240A1_FUNC.lib`，子电路名应为`INA240A1_FUNC`。符号最终需8个端子；引脚按功能核对，不能依据图上左右位置猜。若自建符号，可使用8端通用矩形并标注功能；不要求符号轮廓与实物外观一致。保留源文件，元件保存到用户数据库。

导入后同一INA240功能元件放两份，分别标记原图U2/U4。U3另导入`INA181A1_FUNC.lib`，需6端符号。

## 端口与最终接线核对

下面给出的是模型端口顺序及原图物理脚号。外部电源/分流器/去耦仍需用户在图上实际放置并连线。

| 物理脚/模型端口序号 | INA240功能名 | 原图U2连接 | 原图U4连接 |
|---|---|---|---|
| 1 | INM / IN− | VIN | V_CAP |
| 2 | GND | 公共地 | 公共地 |
| 3 | REF2 | 公共地 | 公共地 |
| 4 | NC | 悬空 | 悬空 |
| 5 | OUT | IIN_RAW | IL_BI |
| 6 | VS | +3V3_A | +3V3_A |
| 7 | REF1 | 公共地 | +3V3_A |
| 8 | INP / IN+ | V_SHUNT_IN | L_RAW |

| 物理脚/模型端口序号 | INA181功能名 | 原图U3连接 |
|---|---|---|
| 1 | OUT | IOUT_RAW |
| 2 | GND | 公共地 |
| 3 | INP / IN+ | V_CAP |
| 4 | INM / IN− | VOUT |
| 5 | REF | 公共地 |
| 6 | VS | +3V3_A |

U2、U3、U4各有原图100nF去耦电容，接+3V3_A与公共地。模拟电源按原图由+3V3经R_VDDA=10Ω得到，C_A1/C_A2/C_A3分别为1uF/100nF/10uF；不能把DRV_EN信号接成供电。

U2/U3参考为零，名义输出为20倍分流器差压。U4参考为两REF脚平均值，名义输出为模拟电源一半加20倍差压。RS_IN/RS_OUT均50mΩ，RS_L为25mΩ；所以U2/U3约1V/A，U4约中点加0.5V/A。输入方向以表中INP/INM为准。

## 验证和限制

运行`python verify_and_package.py`，需要numpy及ngspice，后者可用环境变量NGSPICE指定。脚本核对原Rev B逐引脚CSV，运行正负差压DC扫描及三路阶跃，检查输入/输出采样的1V/A、电感采样中点/0.5V/A及功能模型上下轨限幅。阶跃只验证自行设定的1us极点，不证明真实芯片响应。

本模型无输入负载、偏移、静态供电电流、共模电压相关误差、动态供电电流、热或噪声；不能把大共模下功能增益保持解释为CMRR合格，也不能用它预测R_VDDA上真实器件Iq造成的压降或整机效率。输出限幅发生在内部滤波之前，掉电时残留状态按假设极点衰减，不等同真实欠压关断。

本目录不含原生.ms14；Windows Multisim导入、引脚映射及主图运行均待本机确认。现有Ki20及此前V_EN内部保护诊断文件不改动。
