## 本轮变动

- 同步 Rev C.2 的全部 120 项器件及 51 个网络，保留 J_MON.1→PA6、LCD SCK→PA5，以及 IR2184 驱动和原保护门限。
- J1/J2/J_BYP/J_MON 改为图片中的 2.54 mm 端子；C1/C3 按直径 10 mm、脚距 5 mm 重建；C2/C4/C6及本轮用户确认的C_A3均采用0805。
- L1采用65125立式20×10mm投影、P10。F1按最新资料采用5×20mm、2A快断管及5×20夹；用户确认单夹P5.66，槽0.9×1.5mm。两夹中心距15mm是试装初值，需实装核对；中间6×30/7.7方案作废。
- 分流电阻分别采用商品图封装：**RS_IN/RS_OUT：50mΩ、M型、P10、图示线径0.8mm、体高12mm、标称5A；RS_L：25mΩ、U型、P5、图示线径0.7mm、体高7mm**。RS_L原P10占位已改为P5；实际焊脚径、平面厚度、1%精度/连续功率仍待核。
- 用户确认L1立式，与现布局一致。D1、D_FREE均按用户SR560贴片/SMB（DO-214AA）同步型号，沿用原SMB铜几何与位置；本工程1=K色条端、2=A。厂家电气条件及推荐焊盘最终复核待归档。
- 重新安排功率、驱动、采样和控制器件；采样芯片靠近分流器。补充部分栅极、去耦与 ADC 局部走线。完整布线状态由验证 JSON 如实记录。

## 修改影响

比较基准：原 Rev C.2 原生工程和 PDF；旧 Rev B PCB 仅用于板框与原生格式参考。

**原理图影响：**全部引脚网络保持；同步封装关联和物料说明。F1相对源图保持5×20/2A并补FAST；中间6×30方案撤销。C4由10µF/35V提高为50V，容量保持；D1/D_FREE由源图SS56标注同步为用户SR560/SMB。U1及控制/保护连接保持。

**器件/BOM/PCB 影响：**有封装、耐压、保险管规格及布局变化，需使用本目录 PCB BOM，不能直接使用旧 Rev B 封装采购/制板。IR2184 与参数表已购 IR2104 不可直接互换；RS_L已按25mΩ商品图改P5，当前库存及电气额定待核。其余未确认项见详细说明。

**仿真/固件影响：**本轮没有修改、运行或重新验证 Multisim、ngspice 模型及 STM32 固件。保留源文件不等于验证了 C4 有效容量、所购电感、热设计或实际功率级。

**后续50mΩ图片更新（基准523113a）：**RS_IN/OUT由通用占位改为M型专用封装关联，补充脚距证据；原理图网络、器件数值、铜焊盘/孔径及位置和走线几何保持。没有新增或要求更换50mΩ实物；精度/功率和平面厚度仍待核。RS_L库存按B3补料历史改为待核，不能由旧表自动认定缺货。详见[证据与影响说明](reports/50mΩ商品图确认.md)。

**后续25mΩ图片更新（基准9de6ebe）：**用户DILIN迪林图确认RS_L为U型P5、图示线径0.7mm、体高7mm。两个孔/焊盘从P10各向中心移动2.5mm；孔径1.1mm、焊盘2.6mm和器件中心保持。25mΩ数值、电气网络及仿真/固件保持。详见[25mΩ证据与修改影响](reports/25mΩ商品图确认.md)。

**后续5×20管夹更新（基准6135e14）：**最新管与夹均为5×20，用户确认单夹5.66mm为脚中心距。F1四槽、铜焊盘、包络及规格标注更新；两夹中心距15mm和槽方向保留试装标记。电气网络、2A额定及仿真/固件保持。详见[保险管夹确认与试装要求](reports/F1_5x20夹P5p66确认.md)。

## 打开与复现

最新二极管确认比较11bce99：两只SR560/SMB已同步到工程，铜焊盘、孔位、器件位置及71段走线保持；旧模型未同步为SR560厂家模型，压降/温升/效率未据此重新验收。详见[当前确认记录](../../reports/component-confirmations-2026-10-27/README.md)。

用嘉立创 EDA **专业版**支持 `.eprj2` 的版本打开工程副本，选择 `G题 Rev C.2 — PCB封装与布局修订`，查看 `Rev C2 120x90 — 封装布局复核 / 待完成布线`。默认页指向新 PCB。工程由原生历史记录追加生成，尚未在客户端打开，不能把 SQLite/网络检查当作导入验证。

Python 3.10+，安装 [tools/requirements.txt](tools/requirements.txt)，在仓库目录执行：

```bash
python projects/2026-electronics-contest/g-buck/rev-c2/pcb/hardware-fit-120x90/tools/build_pcb.py
python projects/2026-electronics-contest/g-buck/rev-c2/pcb/hardware-fit-120x90/tools/route_local.py
python projects/2026-electronics-contest/g-buck/rev-c2/pcb/hardware-fit-120x90/tools/verify_pcb.py
python projects/2026-electronics-contest/g-buck/rev-c2/pcb/hardware-fit-120x90/tools/render_pcb.py
```

先构建再布局部线；`route_local.py` 不应直接重复运行在已有走线的工程上。所有预览来自交付工程中的实际坐标和走线，不是客户端截图。1:1 页仅供器件贴合核对；F1装配间距及分流器完整包络等保留假设标记，不能按该页钻孔。

**最新C_A3确认（比较c3892ab）：**10μF/25V保持，由1206占位改0805，两焊盘各向中心移动0.5mm；其余焊盘、所有器件中心/角度和71段既有走线保持。C6/C_A3合并采购2只，总计45行。完整料号/介质及偏压有效容量待核，仿真/固件未改。[确认与修改影响](reports/C_A3_0805确认.md)。复现使用随包的`data/placement_baseline_c3892ab.json`保留位置；后续布局修订须显式修改该输入。
