# Rev C.2 实物装配与首次调试步骤

日期：2026-10-31。比较基准：仓库 b93bb34 的 Rev C.2、当前更新采购清单、PCB实物适配工程及默认诊断固件。用户已说明材料到齐；这不代替型号、极性和实物检查。

## 1. 先核对板子和工具

- 打开[当前PCB说明](../pcb/hardware-fit-120x90/README.md)、[采购清单](updated-bom-2026-10-27/物料清单.md)及[逐引脚接线表](../results/data/RevC2_逐引脚接线表.csv)，装配以实际PCB版本为准，不能把旧Rev B/C的位号、封装和排线混用。
- 仓库PCB目前只是静态全连通草稿，原生ERC/DRC、制造与装配复核未完成，不能直接据此制板。若已有PCB，先核对实际投板文件、网络、铜间距、功率走线承载、封装和未布检查结果；未通过前只备料、试装，不进入焊接/上电。
- 准备可调温烙铁、焊锡、助焊剂、镊子、吸锡带、放大镜、万用表、限流直流电源、ST-Link；功率调试还需示波器、合适的差分/隔离探头和有足够功率额定的假负载。
- 全程断电插拔、焊接。每次断电后测电容残压，放电后再操作。
- 先干装电感、MOS管、散热片、电解电容、端子和保险夹；确认不干涉再焊。F1两夹15mm中心距只是试装初值，不能强压保险管或掰弯夹子补偿错误孔位。

## 2. 分料并贴位号

| 部件 | 装配要求 |
|---|---|
| U1 | IR2184直插DIP8；不能用旧表里的IR2104直接替换 |
| U2/U4、U3 | 分别为INA240A1和INA181A1，封装及脚序不同 |
| QH、QL | IRF540N；按具体厂家顶视图核对1=G、2=D、3=S |
| RS_IN、RS_OUT | 50mΩ，P10；不是50Ω |
| RS_L | 25mΩ，P5；不是25Ω，也不能混到输入/输出分流位置 |
| C7～C10 | 4.7nF/50V/0805/X7R，CL21B472JBANNNC，共4只 |
| C_VINP_ADC | 4.7nF/50V/0805/C0G，共1只，与前一批分开 |
| C_IL_ADC、C_IL_PROT | 1nF/50V/0805/C0G，共2只；不代用另购的1206/X7R |
| 100nF去耦等 | 50V/0805/X7R，共16只，按清单逐位号装 |
| C4、C6、C_A3 | C4为10µF/50V；C6及C_A3为10µF/25V；均0805 |
| R_PRE | 外置22Ω/5W、脉冲耐量≥0.3J，固定后用导线接指定焊盘 |
| R_SN、C_SN | 默认不装，待实际振铃测量后再决定 |
| TP1～TP14 | 默认裸铜测试点，不要求焊测试柱 |

普通电阻与0.1%精密电阻按采购清单分别装；低阻分流器不能靠普通万用表两线读数确认精度。芯片完整型号、二极管极性、电感额定和分流器功率仍需对照实物资料，材料到货不代表这些额定已验收。

## 3. 焊低矮贴片件

1. 先焊0805/1206电阻，再焊贴片电容；一次只拆一种规格，装完勾掉对应位号。
2. 焊BAT54S、BAT54以及SR560，按当前PCB焊盘脚号与网络确定方向。
3. 焊采样芯片、比较器和逻辑芯片：U2/U3/U4、U5/U9、U6/U7/U8。以缺口/圆点确认1脚，不凭文字朝向。
4. 每完成一个区域就放大检查桥连、虚焊和偏移；通断检查对照网络，不能把所有蜂鸣都判为短路。

二极管特别核对：

- D1、D_FREE：当前工程1=K（色条端）、2=A。D1的K接V_SHUNT_IN、A接IN_PRE；D_FREE的K接SW、A接GND。
- D_BOOT为UF4007：工程1=A、2=K，色环为K；不能照搬SR560的焊盘编号规则。
- D_ADC1～6用BAT54S；D_POR用单BAT54，两者不能混装。

## 4. 焊直插件和功率器件

1. 焊U1或合适的DIP8插座，插座与芯片缺口均对准1脚。插芯片前先完成焊接检查。
2. 焊排针及端子：J_CTL、J_AUX12、J_AUX5、J_MON、J1、J2、J_BYP；先焊一脚校正垂直，再焊其余脚。
3. 焊RS_IN/RS_OUT/RS_L及L1，电感按当前立式布局固定，避免重量拉扯焊盘。
4. 焊C1=470µF/50V、C3=470µF/35V。负极条纹对应GND；以网络及板上极性核对，不凭焊盘形状判断。
5. 装QH/QL及散热件。QH的D接VIN、S接SW；QL的D接SW、S接GND。两只金属背板均为漏极，若共用散热片必须正确绝缘，并用万用表确认没有把VIN与SW短接。
6. 干装5×20mm保险管确认夹紧和接触后，取下管再焊牢管夹；最终用2A快断管，不能短接代替。
7. R_PRE固定在耐热、绝缘位置，接到它自己的两个焊盘。J_BYP接常开保持型旁路开关（≥30VDC/3A），开关跨接预充电阻两端；不能接到输入正负之间。

清洁焊剂残留，检查板底长引脚、焊锡珠和安装螺丝是否可能碰铜。

## 5. 单独调好两块辅助电源

先把模块与主板负载分离，用限流电源按模块说明供电，分别调压并检查带载输出；调节后断电再接线。

| 主板脚号 | J_AUX12 → 12V模块 | J_AUX5 → 5V模块 |
|---|---|---|
| 1 | 模块IN+ | 模块IN+ |
| 2 | 模块IN− | 模块IN− |
| 3 | 模块OUT+（12V） | 模块OUT+（5V） |
| 4 | 模块OUT− | 模块OUT− |

这是按脚号接线，不代表模块四角的物理排列。两块模块输入均来自主板预充后的VIN，按网络接入，不绕过预充。12V输出不得接5V或3.3V；不把模块当隔离电源。

## 6. 制作STM32排线

断电，用万用表逐芯核对；排针从顶面/底面看会镜像，不能按“左边第一根”口述插接。

| 主板接口 | STM32核心板 |
|---|---|
| J_CTL.1、3、10、16 | GND |
| J_CTL.2 | 经确认可接受5V的核心板5V输入 |
| J_CTL.4 | 核心板3.3V输出，供主板对应3.3V网络 |
| J_CTL.5 | PA8，PWM |
| J_CTL.6 | PB11，IOUT_OC_N；此脚不是GND |
| J_CTL.7 | PB0，MCU_EN |
| J_CTL.8 | PB1，ARM |
| J_CTL.9 | PB10，FAULT_N |
| J_CTL.11 | PA0，输入电压 |
| J_CTL.12 | PA1，输入电流 |
| J_CTL.13 | PA2，输出电压 |
| J_CTL.14 | PA3，输出电流 |
| J_CTL.15 | PA4，电感电流 |
| J_MON.1 | PA6，下游VIN采样 |
| J_MON.2 | GND |

核心板电源脚功能必须按实际板资料确认；不要将外部5V接到3.3V脚。ST-Link接GND、SWDIO=PA13、SWCLK=PA14及3.3V参考（可接NRST），分清调试器参考脚与供电脚，避免USB、调试器和外部电源互相反灌。

LCD信号：SCK→PA5、MOSI/SDA→PA7、CS→PB12、DC/RS→PB13、RST→PB14、GND共地。PA6留给ADC，不接LCD/SD的MISO。电源及跳线按实际屏幕版本核对；仓库11Pin屏的顺序不是通用8Pin屏顺序，不能盲接。暂不接屏也可编译LCD=0诊断版。可选按键默认不启用，先不增加未确认排线。

## 7. 断电总检查

- 对照实际板文件，检查输入、输出、12V、5V、3.3V对地有无异常低阻；电容充电引起的瞬时低读数需等待稳定后判断，不设一个适用于所有网络的固定阻值。
- 检查QH/QL的G-S、D-S及散热片绝缘；注意体二极管，不能只凭单向导通判定损坏。
- 检查所有芯片1脚、二极管色条、电解正负和排线方向。
- 旁路开关断开、功率使能未开启；J1.1为输入正，J1.2为GND；J2.1为输出正，J2.2为GND。
- 功率负载/真实电池先不接；未确认的短路或接线问题先解决，不靠加大电源限流值试过去。

## 8. 先调辅助电源、采样和关断

1. 在主功率禁止使能的条件下，用受控限流供电检查辅助电源。限流值依据已核实的模块启动和静态消耗设置；持续限流、异常升温或电压不对立即断电查因。
2. 烧录[默认诊断包](../downloads/GBUCK_RevC2_STM32_diagnostic_2026-10-28.zip)内的HEX（BOOT0=0；BIN地址0x08000000）。默认POWER=0，PB0/PB1不允许开启功率；默认版没有输出是预期行为。
3. 在调试器观察debug_status、debug_sample。核实12V、5V、3.3V、模拟VDDA，并确认ADC各脚只处于允许输入范围。
4. 用已知电压/电流校准六路采样：VIN/VOUT/VIN_POST标称11:1；IIN/IOUT标称1V/A；IL为(ADC电压−VDDA/2)/0.5V/A，零电流约1.65V。分流精度、VDDA和偏置以实测校准。
5. 用独立台架或隔离功率开关的方式验证驱动真实使能极性、HO−VS/LO−COM、自举与死区；检查复位/掉电/故障时关断，验证硬件锁存链。高边测量用合适差分/隔离探头，接地探头地夹不能夹SW。
6. 这些检查未通过前保持POWER=0，不因屏幕能亮或软件状态正常就开启功率。

## 9. 受控功率调试与预充旁路

本阶段需要前述检查通过、合适负载和测量条件；仓库固件未上板整定，以下是待执行顺序，不是已经通过的硬件操作结果。

1. 停电接上有足够额定的电阻/电子负载，从小功率恒压调试开始；不用真实电池、满功率或空载作首次闭环试验。检查完成后才构建POWER=1；在OFF/FAULT状态用命令5/6设定电压mV、电流mA，每条命令等待清零后再发下一条。
2. 旁路保持断开、EN关闭，输入先用题目下限15V并限流，电流先经22Ω预充。
3. 用SWD命令1发起预充检查。固件需输入12～27V、下游≥11V且与上游差≤1.5V持续100ms才到READY；这只是软件判据，不是旁路闭合检测，也不扩大硬件额定。
4. 实测下游VIN接近输入、预充无异常且仍关闭功率后，人工闭合旁路开关；再发命令2确认实体旁路已闭合。不能只等100ms就盲目闭合，也不能发软件命令代替闭合实体开关。
5. 发命令3启动（目标值须已在第1步设置），观察软启动、输出、IL、占空比与温升。PI参数仍须实物整定。
6. 异常用命令4停止并核实驱动关闭，必要时切断输入；故障后查因，重新执行预充、旁路确认和启动，不直接清故障重启。
7. 逐步做15V/20Ω、输入15→25V、25V时20→8→5Ω等题目工况；空载、反向电流、保护恢复另行验证。10V加到20Ω/8Ω/5Ω时，负载应至少能承受5W/12.5W/20W并留散热余量；恒流工况实际电压会变化。
8. 不直接短接输出来试保护；先验证检测/关断链，再设计限能故障测试。20ms软件判据与±2.2A硬件电感阈值均不等同于瞬态1A硬限流。

完整[固件操作与故障编号](../firmware/docs/上板调试与操作.md)保留为调试依据。带功率时不要暂停/单步MCU；内核暂停不保证PWM同步停止。
