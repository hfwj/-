# U1 IR2184：用户手册截图与v6工程核对

比较基准：7cf10ec，设计基准为v6 IL_BI清理工程。用户提供IR2184(4)(S)&(PbF)、PD60174 revG手册前三页截图，属于系列共用手册，不单独证明所购实物完整型号。

## 已确认的兼容项

U1原生数值IR2184PbF、封装DIP8_300；8脚网络逐项回读与IR2184引脚定义一致：

| 脚号 | IR2184定义 | 工程网络 |
|---|---|---|
| 1 | IN | PWM_IN |
| 2 | SD（低电平关断） | DRV_EN |
| 3 | COM | GND |
| 4 | LO | LO |
| 5 | VCC | +12V_DRV |
| 6 | VS | SW |
| 7 | HO | HO |
| 8 | VB | VB |

IR2184为8脚PDIP、IR2184S为8脚SOIC；IR21844/IR21844S为14脚且有DT/VSS。不能从本系列手册封面有多个型号就认为全部都能直接替换当前DIP8。

VCC推荐10～20V，当前驱动支路12V符合名义工作范围，不能把表中25V绝对最大值作为正常供电。3.3V输入逻辑兼容，逻辑高判定参数2.7V、低判定0.8V；实际MCU/门电路输出、压降与噪声仍需满足引脚处电平要求。

2脚低使两路输出关闭，高允许驱动；使能状态下IN与HO同相、LO互补并有死区。因此停机不能仅令PWM变低，必须通过关断端禁止驱动，否则低边可能持续导通。当前R_SD_PD=10k从DRV_EN到GND，与复位期间禁止驱动的目标一致；现有board.c在配置输出模式前先将EN/ARM置低，源码逻辑方向一致，未运行实机验证。

C_BOOT=1μF/25V接VB与SW；D_BOOT=UF4007的1/A接+12V_DRV，2/K接VB；C_DRV=1μF/25V和C5=100nF接VCC到COM；两路栅极串阻RG_H/RG_L为4.7Ω。以上为接线与设计值核对，不代表自举有效容量、放电、启动刷新、二极管恢复或实际栅极波形已验证。

IR2184为固定死区，手册相应测试条件下典型400ns、范围280～520ns。IR21844才有外部DT调节端；不能把RDT=200k一栏约5μs的结果用于当前无DT脚的IR2184。典型导通/关断传播延迟约680/270ns，不能把它们与死区混为一个量。表中输出电流1.4/1.8A为相应条件下给定的源/灌最小脉冲值，1.9/2.3A为典型脉冲值；测试VBIAS=15V、脉宽≤10μs，不是12V供电下的连续负载能力。
