# MN11SS4W01 替代 MSS-22D18：按 J_BYP 外接旁路用途登记

比较基准：8fe83d4，用户上传v5对应工程与此前外接辅料表。用户提出“MN11SS4W01替换MSS-22D18”，并给出SPST、4A/30VDC、M6×0.75、面板孔Ø6.5mm、两焊片的信息图。

## 适用范围

当前工程未找到明确标为MSS-22D18的器件。工程中可对应的用途是J_BYP外接预充旁路，原要求保持型SPST、≥30VDC/3A。MN11SS4W01为SPST ON-OFF保持型，厂家标称4A/30VDC，满足这一静态选型要求；不以6A/125VAC替代直流额定判断。

因此将外接辅料表J_BYP配套一项明确为NKK MN11SS4W01，每机1只。此操作是按当前两线旁路用途登记选型，不是已核实任意MSS-22D18六脚接法都能兼容，也不是实物更换/测试已经完成。库存、是否已购及实际旧开关用法未确认。

MSS-22D18通常是6脚DPDT（2P2T）PCB拨动开关；若旧件用到两路独立触点或换向，新件两端SPST不能完成同样功能。应另选相应双刀/换向开关，不能将两路随意并接。旧件具体厂家额定及引脚编号未提供，不从家族名称推定。

## 接线与安装（限J_BYP旁路）

J_BYP.1（FUSED）── MN11SS4W01两端触点 ── J_BYP.2（IN_PRE）

- 两根线分别接两个焊片；无电气极性，不接GND，不把两端都接到同一网络。
- 开关固定在面板，标称开孔Ø6.5mm、螺纹M6×0.75；安装厚度、定位结构、端子绝缘和周围净空以厂家机械图及实物核对，不把6.5mm孔当作唯一机械约束。
- 此为焊片接线型，不直接插入MSS-22D18的六脚PCB孔。当前主板已通过J_BYP的两线接口外接，因此无需改主板铜、走线或Gerber。
- 旁路OPEN时电流仍可经R_PRE预充，不能当整机电源隔离开关。输入上电前旁路OPEN，按现有预充流程保持MCU_EN=0、等待≥100ms且核对下游电压；确认预充后闭合旁路，之后再ARM/使能。停机、断输入电源后恢复OPEN。不在输出运行时用它代替停机控制，不把标称4A当作不受限电容浪涌开断保证。
