## 1. 外置22Ω预充电阻、旁路开关

R_PRE是22Ω/5W、单次脉冲耐量≥0.3J的外置电阻，无极性：两端分别用线接主板R_PRE.1和R_PRE.2。固定在耐热绝缘位置并留散热空间。主板上的R_PRE框不是实物电阻本体尺寸。

常开保持型SPST旁路开关（≥30VDC/3A）的两个触点分别接J_BYP.1和J_BYP.2。电阻和开关在电气上并联：R_PRE.1/J_BYP.1同属FUSED，R_PRE.2/J_BYP.2同属IN_PRE。开关不得接到输入正负两端；不用跳线长期代替预充开关。

```text
FUSED  ──┬── R_PRE：22Ω/5W ──┬── IN_PRE
         └── J_BYP旁路开关 ──┘
```

初次上电开关断开、功率输出关闭；预充后测下游VIN接近输入且无异常，再人工闭合旁路，按固件流程确认与启动。仅等待100ms或发软件确认不代表实体开关已闭合。

## 2. 两块降压模块

M1/M2按各自实物端口标识接线：VIN=IN+、输入端GND=IN−、VOUT=OUT+、输出端GND=OUT−。历史记录选用LM2596HV；最新用户照片中的一块PCB标XL7015_V2，尚未确认正面芯片及其分配为M1还是M2，不能从一块照片推定两块型号。先与主板负载分离，限流供电，分别调为12V和5V，检查后断电接入。模块端不按四角的位置猜顺序。

| 主板脚号 | J_AUX12 → M1（12V） | J_AUX5 → M2（5V） |
|---|---|---|
| 1 | 模块IN+ | 模块IN+ |
| 2 | 模块IN− | 模块IN− |
| 3 | 模块OUT+，调至12V | 模块OUT+，调至5V |
| 4 | 模块OUT− | 模块OUT− |

两模块输入均取主板预充后的VIN，不另跨接J1输入绕过预充。4脚与2脚都是GND，仍按各回路线接好。12V供驱动，5V供逻辑及按实际核心板要求供电。本版板上这两组排针从下到上为1/2/3/4，仍以焊盘脚号核对。

## 3. STM32F103C8T6核心板

J_CTL是2×8、P2.54。与PCB位置图同向看，顶端1/2、底端15/16，左奇右偶。主板端用配套母座，核心板端按实际排针分线连接，不把两块板16针按位置直接一一插接。

| 主板接口 | 核心板端 | 功能/供电方向 |
|---|---|---|
| J_CTL.1、3、10、16 | GND | 地线按线束连接 |
| J_CTL.2 | 经实际板资料确认的5V输入 | 主板5V→核心板；不可接3.3V脚 |
| J_CTL.4 | 经实际板资料确认的3.3V输出 | 核心板3.3V→主板3.3V网络；不能另并未知电源 |
| J_CTL.5 | PA8 | PWM |
| J_CTL.6 | PB11 | IOUT_OC_N；不是GND |
| J_CTL.7 | PB0 | MCU_EN |
| J_CTL.8 | PB1 | ARM |
| J_CTL.9 | PB10 | FAULT_N |
| J_CTL.11 | PA0 | 输入电压ADC |
| J_CTL.12 | PA1 | 输入电流ADC |
| J_CTL.13 | PA2 | 输出电压ADC |
| J_CTL.14 | PA3 | 输出电流ADC |
| J_CTL.15 | PA4 | 电感电流ADC |
| J_MON.1 | PA6 | 预充后VIN电压ADC |
| J_MON.2 | GND | 监测地 |

PA6留给ADC，不接LCD或SD卡MISO。ADC脚不得直接接5V、12V或主输入15～25V。核心板上5V/3.3V引脚、稳压器供电方向与允许负载按实际板确认，芯片型号不能替代核心板电源说明。外部供电、USB、调试器避免互相反灌。

## 4. 屏幕

按实际屏幕的信号名称接线。以下编号只适用于仓库归档的全动11Pin屏，若实物是其他版本，使用信号名映射并重新核对供电，不能套编号。

| 屏幕信号 | STM32 / 电源端 | 归档11Pin屏脚号 |
|---|---|---|
| VCC | 按实际模块要求接5V或3.3V | 1 |
| GND | 共地 | 2、3 |
| NC | 不接 | 4、5、6 |
| SCK / SCL / CLK | PA5 | 7 |
| SDA / MOSI / DIN | PA7 | 8 |
| RS / DC / A0 | PB13 | 9 |
| RST / RES | PB14 | 10 |
| CS | PB12 | 11 |

归档11Pin版本的供电要求：VCC=5V时屏幕自身J1跳线断开，VCC=3.3V时屏幕自身J1短接。这里的J1是屏幕跳线，不是主功率板输入端子。实际屏幕背光BL/LED若有独立引脚、限流或跳线，需按该屏幕资料确认，不能直接接未知电压。PA6不作MISO。

## 5. 输入电源与负载

| 主板接口 | 外部接线 |
|---|---|
| J1.1 | 15～25V直流输入正极，首次用限流电源 |
| J1.2 | 输入负极/GND |
| J2.1 | 假负载正端/电阻负载一端 |
| J2.2 | 假负载负端/电阻负载另一端 |

首次闭环测试用适当额定的假负载，不接真实电池。输出设定、负载功率与散热需匹配；功率线、开关线和端子按实际电流额定选择，不以细信号杜邦线代替。

## 6. 调试器与首次检查

ST-Link：SWDIO→PA13、SWCLK→PA14、GND→GND，按调试器说明连接3.3V参考（可接NRST）。参考/检测引脚不自动等同于供电输出，不将多路电源直接并联。BOOT0=0，先烧录默认POWER=0诊断固件。

接完后逐线导通检查；先验证12V、5V、3.3V及六路采样和驱动关断，再安排受控功率调试。默认诊断固件不会开启功率，不能因无输出就直接闭合旁路或强拉使能。可选按键默认未启用，暂不按未确认GPIO增加按键。完整启动流程见[固件上板操作](../../firmware/docs/上板调试与操作.md)。
