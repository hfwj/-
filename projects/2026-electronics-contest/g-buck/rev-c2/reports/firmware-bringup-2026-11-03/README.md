# A1诊断固件：用户上板复测记录

日期：2026-11-03（北京时间）。比较基准：A1发布提交`660a38db1e50648b254b3846872b12072adeab8b`及其中的2026-10-28旧固件问题记录。来源为用户在对话中提供的现场屏幕照片；本环境未直接连接目标板，也未采集示波器或ADC原始记录。

## 照片确认的状态

| 项目 | 照片读数 |
|---|---|
| 标题 | GBUCK C2 LOCKED A1 |
| 状态/故障码 | OFF / FAULT 0 |
| VIN | 14.865 V |
| IIN | 0.033 A |
| VOUT / IOUT | 0.000 V / 0.000 A |
| SET V / SET A | 10.000 V / 1.000 A |
| POST | 13.589 V |
| IL | -0.026 A |
| 底部 | CONFIRM BYPASS / SWD CONTROL |

用户此前在旧版下报告J1.1=15V、J_CTL.11=1.35V、PA0=1.35V，但屏幕VIN=0V；此次A1照片中VIN不再为0。A1已由用户刷入并至少运行至该照片状态，不能再笼统记为“A1完全未上板”。但本次没有同时提供新的万用表读数或受控前后对比，不能证明唯一因果、ADC精度合格、所有通道已校准、冷启动可靠或保护链全部通过。

OFF状态下FAULT 0只表示当前无软件故障锁存，不等同于全套采样/保护自检完成。0.033A输入电流可能包含辅助电源等消耗，需对照电源或独立电流表；IL的-0.026A需要在确定零电流条件下核查偏置，不能未经验证直接软件归零。VIN与POST相差1.276V，旁路断开且存在辅助负载时可能有预充电阻及串联器件压降，仍需实测核对，不能只凭两项显示验收预充回路。

## 前一张OFF照片后的检查计划（历史）

- 确认临时隔离的J_CTL.9→PB10故障线已经恢复；若未恢复，先断电并确认电容放电再接，不把断线时的FAULT 0当作保护链健康证明。
- 保持POWER=0、15V受限流输入和旁路断开。使用Hot Plug向A1 `debug_command=0x2000009C`写入32位命令1；命令处理后归零，只发起软件预充/健康检查，不驱动实体旁路，也不发ARM。
- 按当前照片，VIN在12～27V软件检查范围内，POST大于11V且与VIN相差小于1.5V；这些条件与其他健康条件保持100ms后，预期进入READY、FAULT 0。实测结果仍待反馈。
- 暂不发送命令2（旁路确认）/3（START），不更换POWER=1。READY本身不能证明实体旁路已闭合，更不能作为功率级或保护验收。

## 本轮续接：已出现READY（2026-11-03）

用户提供了新的现场照片，屏幕标题仍为 `GBUCK C2 LOCKED A1`。以下为照片转录，不是本环境直接测量：

| 项目 | 本轮照片读数 |
|---|---|

| VIN / POST | 14.847 V / 13.686 V |
| IIN | 0.026 A |
| VOUT / IOUT | 0.000 V / 0.000 A |
| SET V / SET A | 10.000 V / 1.000 A |
| IL | -0.004 A |
| 底部 | CONFIRM BYPASS / SWD CONTROL |

VIN−POST=1.161V，显示值符合A1的12～27V输入、POST≥11V、压差≤1.5V预充条件。与前一张OFF照片相比，本轮已观察到READY，前文“预充READY待反馈”的待办据此更新为“已观察到一次READY”。照片不能证明持续运行、ADC精度、物理旁路状态、故障线已恢复或保护链动态性能。输入电流与IL读数变化不能单凭照片解释为校准完成。

用户说明此前测量“都有记录”。沿用上文及ADC修订说明中的既有测量，不重复把旧测量列为待提供；PB10/PB11此前稳态高、旧PA0约1.35V以及静态VGS为0仍保留其原有条件和验证边界。特别是曾临时断开J_CTL.9→PB10，现有照片无法确认已经恢复。

### 下一步：保持A1锁定版，核对实体旁路并确认

1. 先核实此前临时隔离的J_CTL.9→PB10已经恢复，且当前无故障、异常发热或供电持续限流；若仍未恢复，先断电并确认电容放电再接，重新上电按原命令1流程回到READY。不能用断线后的高电平替代故障链连接。
2. 保持现有A1、POWER=0、约15V受限流供电及功率输出关闭。按已有接线记录确认J_BYP是跨接预充电阻两端的已安装旁路开关；不在带电状态临时插拔导线或搭接短路线。
3. 在下游电压实测已接近输入、没有异常且仍为READY的条件下，操作已核对的实体旁路开关闭合。比较闭合前后实际VIN与POST；预充电阻两端压降应明显减小。若压差仍约1V、持续限流、发热或状态变为FAULT，先停止，不把它当作旁路已正确闭合。
4. 只有实体旁路确已闭合后，使用既有Hot Plug方式在A1专用地址 `0x2000009C` 写入一个32位数值 `0x00000002`（命令2，CONFIRM_BYPASS）。等命令归零；预期屏幕显示 `BYPASS CONFIRMED`、仍为READY / FAULT 0、输出仍关闭。软件提示仅记录人工确认，不检测开关触点。
5. 本轮停在旁路确认。命令3、POWER=1和功率调试仍待六路采样/驱动关断/硬件保护及实际门极测量核查，不因READY直接放行。旧版 `0x2000007C` 不适用于A1；重新编译的镜像须重新核对MAP地址。

下一次只续接新的旁路操作结果及尚缺的验证项，不要求重做已经有条件明确的测量。当前无新增固件版本，无需重刷A1。
