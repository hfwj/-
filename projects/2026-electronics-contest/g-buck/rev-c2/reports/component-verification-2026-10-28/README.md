## 下一步收集与冻结顺序

1. 先取得 **L1和J_BYP实际完整型号/购买链接**。若只有“65125／6A Max”或“MSS-22D18”，就按原标注提供，不能补造厂家型号。
2. 重新下单前先完成可能影响几何的实装：F1两夹15mm、MOS真实本体/散热片与C2/D_FREE空间、分流器引脚和本体包络、电感立式占位。使用[v4的1:1 PDF](../../pcb/power-layout-v4-120x90/previews/Footprint_1to1_CHECK_ONLY.pdf)按100%打印核对。仅核P5.66不能代替整个保险管组件试装。
3. 取得R_PRE、F1、电解、分流器及SMD SR560对应厂家资料；参数缺项保留待核。低阻实测使用四线法；额定功率/分断等不能以单次通断或电阻测试代替。
4. 完成选型后，再核v4原生ERC/DRC、新Gerber和生产稿。此次没有运行这些客户端步骤；旧v3通过的导出检查不能转移为v4结论。上电后的电感/半导体/电容温升、波形和保护测试另记为实测。

## 厂家资料与适用边界

访问日期均为2026-10-28。下列资料用于说明核查方法；除了实际型号已对应的项目，不作为用户所购器件的额定证明。

3. [Littelfuse：Fuse Fundamentals](https://www.littelfuse.com/assetdocs/fuse-fundamentals-at-the-heart-of-electrical-systems-fuses-keep-operations-live?assetguid=55d2e833-b53b-467f-a0c2-f15ff2316db3)：额定电压、AC/DC和分断能力须按实际应用分别核定。
4. [Infineon：IRF540N 数据手册](https://www.infineon.com/assets/row/public/documents/24/49/infineon-irf540n-datasheet-en.pdf)：TO-220脚位、漏极背板及热额定的条件。未核定的厂家实物不能直接沿用该厂全部额定。
5. [Samsung Electro-Mechanics：MLCC DC Bias技术说明](https://www.sem.samsung.co.kr/kr/support/library/technical-documents/view.do?id=41)：Class II有效容量会随直流偏压变化；用户C2/C4的具体曲线尚未获得。[MLCC编码参考](https://product.samsungsem.com/resources/file/product-catalog/MLCC_Automotive_2512.pdf)仅辅助核对既有料号记录。
