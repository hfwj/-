# 上板调试与操作

## 先做默认禁止功率输出版

1. 断电检查焊接、短路、方向、电源和控制板排线；归档实际投板文件与原生 ERC/DRC 结果。仓库旧记录未证明这一项完成。
2. 采用限流电源，先核实辅助电源与 ADC 输入电压；默认固件所有状态均不能拉高 PB0/PB1。示波器验证复位、掉电和软件故障期间驱动关闭。
3. 烧录默认 HEX。观察 `debug_status`、`debug_sample`；显示是 ST7735 128×160 起始配置，如空白/错位/反色，调整 `LCD_*` 或用 `LCD=0` 排除显示问题。
4. 用万用表校准 VDDA，更新 `ADC_VDDA_MV`。分别施加已知电压/电流，核对六通道。标称 VIN/VOUT/VIN_POST 为 11:1；IIN/IOUT 为 1V/A；IL 为 `(ADC电压−VDDA/2) / 0.5V/A`，有符号。校准公式 `(标称物理值 + offset) × gain_ppm / 1e6`，偏置单位 mV/mA，初值零/1000000。
5. 输入全量程饱和、IL 近零/满量程判无效；这些不能检测所有断线/卡死情况。不得以软件通过代替模拟采样链测试。
6. 在驱动不接功率开关或合适的独立台架条件下，验证 IR2184 真实关断极性、自举供电、HO−VS / LO−COM、死区与故障硬件链。高边门极必须使用合适差分/隔离测量，不能用接地探头夹 SW。

## SWD 命令入口

调试器连接后，`debug_status` 和 `debug_sample` 是只读观察快照，不要直接改 `app`。
向 `debug_value` 写参数，再向 `debug_command` 写命令编号，等它被 1ms ISR 清零后发下一条；ARM GDB 示例：

| 编号 | 命令 | 条件/作用 |
|---|---|---|
| 1 | PRECHARGE | OFF/FAULT 下明确发起重新检查；故障源健康才清除 EXTI 软件记忆 |
| 2 | CONFIRM_BYPASS | READY 下由操作者确认实体旁路已闭合；绝非接触状态自动检测 |
| 3 | START | READY + 旁路确认 + POWER=1 才发 ARM 并软启动 |
| 4 | STOP | 关闭 EN/ARM/PWM，清除启动许可，保留设定值 |
| 5 | SET_V | 停机/故障状态设置 mV，限 200～10000 |
| 6 | SET_I | 停机/故障状态设置 mA，限 100～1000 |

例如设置 10V / 1A：

```gdb
set var debug_value = 10000
set var debug_command = 5
# 等命令清零
set var debug_value = 1000
set var debug_command = 6
```

运行时不要单步/暂停 MCU；默认外设在内核停止时可能继续保持输出，看门狗也会继续计时。带功率调试应使用运行中读取/日志，停止与改参数先执行 STOP 并核实关断。

## 实体旁路及启动

在输出已关闭的条件下按实际电路操作预充/旁路。命令 1 进入预充检查；只有输入处于 12～27V、下游≥11V 且与上游相差≤1.5V 连续 100ms 才变 READY。输入范围是软件调试边界，不是扩大器件工作范围；题目测试仍为 15～25V。

达到 READY 仅证明下游电容电压接近，**不能证明旁路已闭合**。操作者按 C.2 实体预充步骤闭合并确认旁路后发命令 2，再发命令 3。固件没有旁路继电器输出，不能自动控制 J_BYP。

POWER=1 时：EN 低下发约 1ms ARM 正脉冲，再等待约 1ms；健康时开启 EN 并软启动。故障会关闭驱动并锁存；源恢复后也必须重新执行预充、旁路确认、启动。默认 POWER=0 的命令 3 无效，可用来验证整个诊断流程。

## 可选按键：仅控制板，默认未启用

C.2 主板没有给出按键引脚。以下是新增的可配置控制板方案，尚未证明实际控制板空闲，**不是已确认接线**：

| 接脚，另一端到 GND | 功能 |
|---|---|
| PB5 | 选择电压/电流设定；屏幕底部显示选择 |
| PB6 | 增加 0.1V / 0.05A |
| PB7 | 减少 0.1V / 0.05A |
| PB8 | OFF/FAULT 发起检查；READY 第一次确认旁路，第二次启动；其它状态停止 |

上拉输入，20ms 去抖，按下触发、不连发。只允许停机/故障状态改设定。启用前核对引脚空闲、电平、按键安装与对应源码；按键/排线可能需要额外实物，不要求改主功率 PCB。默认可通过 SWD 完成设置与启动。

## 受控功率测试（未完成）

先核对 EN 极性/硬件关断，再构建 POWER=1，用限流供电和合适负载逐步整定 PI。不要直接以满功率、空载或真实电池作为首次闭环测试。当前是 1kHz 软件控制＋30kHz PWM，**不保证高速电感限流或瞬态最大 1A**；±2.2A 硬件链与软件 20ms 告警是不同层次。

1. 检查一次采样/控制总用时、周期抖动、FAULT→EN 延迟、复位与看门狗关断；不能把 1ms 任务周期当作硬件纳秒关断时间。
2. 先调稳定小功率恒压，再核实恒流切换、积分跟踪和软启动。`CV_KP/KI`、`CC_KP/KI` 只是未整定起点，保留分数积分避免整数死区。
3. 空载同步 Buck 可能反向电感电流，软件当前没有逐周期二极管仿真；必须单独验证空载稳定性和反灌，再进行题目的空载验收。
4. 按题目验证 15V 空载/20Ω、15→25V 源变化、25V 的 20→8→5Ω；记录电压、电流、IL、占空比、模式及恢复。
5. 用受控负载与限能措施验证过流、低压、故障恢复；先验证检测链，再安排低阻测试。20ms 判据不保证短路能量已满足所有器件限制。
6. 从同一路输入测量完整系统功率，计入辅助电源、屏幕、主控；≥85% 必须实测。显示与设定精度也要用外部仪表验收。

故障编号：0=无；1=硬件 FAULT；2=ADC；3=输入/下游欠压；4=持续过流；5=持续低输出；6=输出>11.5V；7=控制时序异常。固定 11.5V 是附加软件门限，不替代硬件保护。
