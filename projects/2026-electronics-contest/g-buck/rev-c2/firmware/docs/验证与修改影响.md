# 验证与修改影响

比较基准：`94c495e`，Rev C.2；2026-10-28（北京时间）。

## 已执行

- GNU Arm Embedded GCC 12.2.1，Cortex-M3/Thumb，`-Wall -Wextra -Werror`，64KB Flash / 20KB RAM 链接成功。
- 三配置通过：默认禁止输出/LCD 开/按键关；允许台架功率输出/LCD 开/可选按键开；禁止输出/LCD 关/按键关。
- 默认镜像 text=4800、data=24、bss=228 字节；RAM 静态占用252字节，链接脚本另保留至少2KB栈余量。这不是实测最深栈用量或 ISR 最坏执行时间。
- 检查三配置 BIN 的初始栈 0x20005000、Reset/核心异常/SysTick/EXTI40 向量的 Thumb 位和 Flash 范围；镜像与 SHA256 见 `build_manifest.json`。
- 主机 GCC AddressSanitizer / UBSan 测试通过：预充100ms边界、旁路确认、ARM高/低时序、软启动、20ms OC/UV边界、短脉冲复位、不依赖OC的低压分支、低目标/启动屏蔽、锁存不自动恢复、输入/下游异常、ADC异常、过压、停机/参数范围、运行禁止改设定、 signed IL比例、ADC满量程、占空比边界与分数积分。
- 另以默认 POWER=0 编译主机测试，确认收到完整启动命令后仍不 ARM、不 EN、不输出占空比。
- 环境不支持 LeakSanitizer 的进程追踪，因此仅设置 `ASAN_OPTIONS=detect_leaks=0`；保留地址与未定义行为检查。代码不用动态内存。

测试调用的是实际 `src/app.c` / `src/measurement.c`，不是复制一套保护模型；未将硬件寄存器、屏幕、按键或启动代码在主机上模拟为“实测通过”。

## 未执行/限制

没有真实 STM32、LCD、功率板、示波器或负载；没有完成烧录、屏幕亮屏、实际按键、ADC精度、控制用时/抖动、门极死区、关断延迟、看门狗复位和冷启动测量。

没有做整机闭环动态/环路稳定性、空载反向电流、故障能量与瞬态1A约束、效率≥85%或题目验收。CV/CC 参数是未整定起点；1kHz软件算法不等于仿真的平均电流模型，不能据此引用旧波形性能。详细待办见上板说明。

## 修改影响

- **原理图影响：**相对 `94c495e` 的 C.2，不改变任何原理图连接、主板端口、器件数值。PA6监测、PB11告警等按已有C.2接口实现。
- **器件/BOM/PCB影响：**主功率板无改动、无新增采购要求。实际控制板型号、屏幕具体模块尚未提供；PB5～PB8四按键是默认关闭的可选控制板方案，空闲性/安装/是否需补购和接线未确认，不能声称实物完全无需改动。
- **仿真/模型影响：**不修改SPICE/Multisim、刺激或旧结果；新增实际C固件与主机输入测试，不把它们当成电路仿真或硬件验证。实际闭环控制采用新双PI策略，因此旧功能模型不能验证其稳定性。

源代码、编译说明、上板检查表和默认诊断镜像分类归档；历史PCB与仿真说明保持原样。
