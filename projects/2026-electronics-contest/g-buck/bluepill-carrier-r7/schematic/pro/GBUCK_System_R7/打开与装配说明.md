# R7：适配用户选购的STM32F103C8T6核心板

比较基准：2fcaa7d/R6。此次按用户商品引脚图、尺寸图及明确答复“GND”，将WeAct核心板替换为截图同款Blue Pill最小系统板。厂家、完整板号和板载稳压器型号未提供，不把商品宣传图当作已核验的厂家原理图或实物测试。

## 本次实际修改

|项目|R6|R7|
|---|---|---|
|核心板MCORE|WeAct BluePill-Plus V1.1|用户选购STM32F103C8T6 Blue Pill，向下已焊排针、USB端上排首针GND版|
|JCORE1.1|VCC名称、底板NC|GND名称、真实导线接GND|
|两排中心距要求|15.22mm|**15.24mm**|
|GPIO、阻容标称值|R6配置|保留，不改|
|屏幕|Joy-IT SBC-LCD84x48 Rev.2|保留，不改|

主控底板仍17件88脚；新增接地后NC由23变为22个，真实导线段由74变为75段。不是仅改文字：最终Pro工程中JCORE1.1已接地。全系统仍73件263脚，另采购核心板、屏幕两个成品模块，不重复计入内部零件。

## 插座编号与方向

**从核心板元件面看，USB接口朝左：上排叫P1，对应底板JCORE1；下排叫P2，对应JCORE2。每排均从左侧USB端编号1至20。** P1/P2/1至20是本设计建立的安装编号，不声称是卖家原厂接插件编号，更不是STM32的LQFP48脚号。换成PCB底视图时会镜像，不能照抄。

|本版编号|从USB端向右的完整顺序|
|---|---|
|P1 / JCORE1|1 GND、2 GND、3 3V3、4 NRST、5 PB11、6 PB10、7 PB1、8 PB0、9 PA7、10 PA6、11 PA5、12 PA4、13 PA3、14 PA2、15 PA1、16 PA0、17 PC15、18 PC14、19 PC13、20 VB|
|P2 / JCORE2|1 PB12、2 PB13、3 PB14、4 PB15、5 PA8、6 PA9、7 PA10、8 PA11、9 PA12、10 PA15、11 PB3、12 PB4、13 PB5、14 PB6、15 PB7、16 PB8、17 PB9、18 5V、19 GND、20 3V3|

商品图片之间存在首针标注差异，本版**以用户确认的GND版本为准**。到货必须检查该位置与板上GND导通，再插底板；其他首针为5V的同外观板不能直接代入。完整每针网络见Core_Socket_Map_R7.csv和BOM Excel。

## 实际信号连接

|底板插座|信号|用途|
|---|---|---|
|JCORE1.1、.2；JCORE2.19|GND|接地|
|JCORE1.3；JCORE2.20|3V3|辅助电源提供3.3V|
|JCORE1.6|PB10|KEY_DOWN|
|JCORE1.7 / .8 / .9|PB1 / PB0 / PA7|LCD_RST / LCD_DC / LCD_DIN|
|JCORE1.11 / .12|PA5 / PA4|LCD_CLK / LCD_CE|
|JCORE1.14 / .15|PA2 / PA1|VOUT_ADC / ISENSE，ADC_IN2 / ADC_IN1|
|JCORE2.5 / .6 / .7|PA8 / PA9 / PA10|RUN / KEY_SET / KEY_UP|
|JCORE2.14 / .15|PB6 / PB7|SCL / SDA|

其他侧排针在底板NC；不表示核心板内部未连接这些脚。PA0继续不用，是为了保留R6固件映射；本款图中没有R6 WeAct的PA0用户按键，不再以该按键作为禁用理由。BOOT0和BOOT1跳帽正常运行都置0；下载/复位用模块自身接口与按钮。PC13为模块指示灯脚，底板不占用。

模块末端四针SWD按商品图，从3.3V标注端依次为3.3V、DIO（PA13）、CLK（PA14）、GND；核对丝印接线，不沿用旧R5底板JSWD的顺序。若使用支持目标自供电/VTref的ST-Link，3.3V作参考，不并联调试器的电源输出。

屏幕保持Rev.2：JLCD.1 GND、.2 LIGHT接GND常亮、.3 +3V3、.4 CLK、.5 DIN、.6 DC、.7 CE、.8 RST。五个GPIO和PCD8544驱动类型不变，不能插Rev.1。

## 供电与拼装

主板J4P/J4N→辅助板J1P/J1N，15–25V/GND；辅助板J2P/J2N→主控JPP/JPN，3.3V/GND。板凳柱每只四脚同网，承流按各路实际工况核对，不恢复统一≥5A要求；L1的Isat≥5A要求保留。

核心板由3V3脚供电，**JCORE1.1是GND，绝不能接正电源**。5V脚JCORE2.18在底板NC且不接外部负载；正常辅助供电时USB拔掉，不并联另一电源。板载稳压器型号和输出侧外供3.3V时的反灌、启动尚需实物核对。商品“800mA”不作为本设计供电能力依据。

辅助电源保持原自设计3.3V，0.3A仍为待验证目标。R6遗留的屏幕2.7–3.3V工作上限与辅助输出正容差问题未因换核心板消失；本次未修改辅助电源，也未宣称供电全温/容差已经验收。

## 器件、封装与制造影响

JCORE1/JCORE2保留Harwin M20-7822046（1×20、2.54mm、通孔排母）两条，JLCD保留M20-7820846（1×8）。排母板上高8.5mm、适配0.64mm方针，仍须核对模块实物针长和插入配合；未核实的立创料号不虚构。原基础库阻容建议保持，板凳柱、按键及其他历史待定件沿用原核实状态。

必须更新核心板采购项与主控底板的两排安装位置。15.24mm是**排间中心距**，单排相邻针节距仍2.54mm。商品尺寸图标53.34×22.86mm，另一图约53×22.5mm，故仅作为占位参考，外形、USB/SWD伸出量和禁布区以到货复核为准。此工程未包含PCB或绑定封装，不存在已完成的PCB排母移动；尺寸只更新在原理图说明、BOM及安装要求中。

保留通孔接口，目标工厂完成“贴片＋插件”焊接。两个模块单独采购且需已焊向下直排针，再插装；代购/预焊/插装不默认包含在底板SMT服务内，以订单审核为准。丝印标清P1/P2、Pin1、USB端，预留按键、SWD、USB和屏幕支撑空间，断电拔插。

## 固件、模型与验证

相对R6，固件GPIO、ADC通道、LCD驱动及控制逻辑**不需因本次适配而改变**，参考头文件只更新模块身份说明。仍使用PA2/ADC_IN2测电压、PA1/ADC_IN1测电流、PB10作减少键；若从R5旧固件迁移，仍须落实R6已经要求的这两处改脚。可以继续使用HSI策略；模块带8MHz晶振不意味着固件自动完成HSE/PLL配置。

仿真模型、补偿参数及既有动态结论未改；没有增加硬件测试，不据此证明效率、瞬时限流、7V设定余量或C14偏压容量满足要求。

本轮实际检查：标准几何及最终Pro嵌入符号/真实导线逐针核对，17件88脚、22 NC、75导线段，零网络错误；与R6比较**唯一引脚网络变化为JCORE1.1：NC→GND**。主板J3/主控J1十针映射一致，主功率/辅助图页与R6逐字节相同；屏幕各脚映射保留。另生成六区PDF和PNG预览，校验最终ZIP完整性及BOM数量。官方格式Schema结果见results/data/schema_check.json。

本轮未复用R6的查看器截图冒充R7验证；R7未运行官方只读查看器或嘉立创原生编辑器打开保存/ERC/DRC。未绑定封装、未做PCB、未验收实物与代焊订单，不能直接投板。

解压工程包，打开GBUCK_Control_R7或GBUCK_System_R7文件夹中的.eprj3，必须同时保留sch目录。references/generated的标准版JSON仅为生成输入，不是最终交付格式。

复现：仓库根目录依次运行tools/build_bluepill_r7.py、tools/render_blocks_r7.py和tools/package_bluepill_r7.py（均在本版本目录下）。格式检查复用mainboard-r2/tools/validate_pro_records.cjs并传入外部官方easyeda/easyeda-format-skill路径。源图依据记录在results/data/Module_Pinout_Evidence_R7.json。
