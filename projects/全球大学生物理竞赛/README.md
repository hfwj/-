## 归档原则

`reports/` 保存报告；`simulation/` 保存可复算代码；`results/` 保存数据、图和数值检查日志；`references/` 记录来源；`downloads/` 保存便于下载的资料包。

相对归档前状态：新增独立物理竞赛项目。不改变现有电子设计原理图、器件/BOM、PCB或固件；新增点球模型与资料和电子电赛工程相互独立。
