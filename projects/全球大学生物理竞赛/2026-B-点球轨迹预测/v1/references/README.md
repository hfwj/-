## 借鉴边界

2022题主要研究给定初速度和自旋的射门策略，2026题要求从早期位置反推未来轨迹。可参考正向动力学，观测反演、参数先验、预测分布和覆盖率需独立实现及验证。获奖不等于所有公式和参数均可直接使用。
