## 模型与代表性结果

采用三维有效模型 `dr/dt = v`、`dv/dt = -g*e_z - k*|v|*v + Omega × v`，主算例设无风、系数不变。

在额外假设 `Omega` 沿早期飞行方向的分量为零时，约 **0.401 s** 到达球门平面，球心交点约 **(11, 2.60, 1.96) m**。这是补充假设下的代表解，不是题目数据唯一决定的答案，也不是已校准的最可能点。

两次三维观测只有 6 个标量信息，初速度、阻力和有效旋转向量共有 7 个未知量；多组参数可吻合相同观测。
