# A题 v6：可运行的正向平动模型 M0

[Word运行说明](reports/正向动力学模型_运行说明.docx) · [PDF](reports/正向动力学模型_运行说明.pdf) · [核查日志](results/logs/verification.json)

在本版 simulation 目录运行 `python forward.py`；依赖 numpy、scipy。结果见 [summary.json](results/data/summary.json)，轨迹CSV同时保存。

输入：初始推进剂70 t（演示H），其中0.5%不可用；初始高度70 km、水平速率1666.667 m/s。比较无推力、60 s指令点火、85 s指令点火三种工况；后两种均命令两台燃烧40 s。发动机虚拟名义推力每台1 MN，比冲320 s，最大节流1.1；点火延迟0.5 s，节流采用时间常数0.1 s的一阶响应（新增H）且变化速率不超过1/s，关机也有限响应。

状态为地心二维位置/速度、可用推进剂、累计推力冲量和等效节流。动力学使用球形地球变重力、0–70 km分层标准大气、Cd=0.5、变质量和实际推力质量流率。按指令时刻分段积分；接触、耗尽、环境上界或时间上限终止。积分内部大气边界试探使用边界值，正式越上界即终止，不能作为高层大气模型。

**本版跑通不等于安全着陆。** 推力方向取理想逆速度方向，没有实现v4的姿态/转向速率权限及完整发动机重启计数；不主动裁剪推力掩盖载荷超限。接触事件以假定竖直箭体质心高度32.5 m定位，只是参考事件，不是完整C10包络检测。船位及相对甲板速度、C13a/b、热/结构与接触后稳定性均未验证。没有实现姿态动力学、制导或燃料优化。

质量—冲量恒等式通过；85 s工况使用0.1/0.05 s最大步长比较终止速率。q和n峰值为输出采样诊断，尚未完成连续峰值约束认证。所有初始推进剂和指令均手工给定，不能当作本题所需燃料答案。
