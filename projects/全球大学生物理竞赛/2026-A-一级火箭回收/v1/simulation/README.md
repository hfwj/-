# 参数复算（不是下降仿真）

Python 3，仅使用标准库。在本目录运行：

```bash
python parameter_checks.py
```

输出到`../results/data/`和`../results/logs/`。脚本复算几何高度0–70 km的USSA1976低层定组成大气、给定量的SI换算、球对称重力与可选虚拟发动机的量级。超过70 km会明确报错，不能把本表外推给继续上升的火箭。

`parameters.csv/json`是报告中的人工整理主参数表，不由本脚本修改。若改变标准常数或参考几何，需同步修订主参数表和报告。

已执行海平面基准、层边界连续性、压强单调性、推重比/质量比例及越界检查。这只支持参数算术一致性；不代表发动机实机性能、气动标定、下降轨迹、热安全或所需燃料量已验证。

原理图、器件/BOM、PCB、固件和旧模型不受影响。对照基线见项目README。
