### 1.1 题目尚不能唯一确定燃料量

分离航迹角、发动机推力/比冲、气动系数及安全约束均未给出。论文应报告“在明确参数与约束下的所需推进剂”，并给出敏感性或情景范围。不能直接把1666.667 m/s当作竖直向下速度。

统一口径：m_p 指液氧＋甲烷总推进剂；m_CH4 单列为甲烷燃料。分离总质量 m₀ = m_d + m_p,0；结论要区分理论消耗、不可用残余、启动耗剂与安全储备。

### 3.1 推荐采用“同一发动机族”的参数口径

要计算燃料消耗，推力T与比冲Isp必须属于同一发动机、同一喷管、同一环境压强与节流状态。不要把BE-4的大推力与Prometheus的比冲拼成已验证性能。可先把它们作为两类量级参考。

T = ΣT_i(p_a,u_i)；  dm/dt = −Σ[T_i/(Isp_i g₀)]

如果只有真空推力，固定工作点的理想关系为T(p_a)=T_vac−p_a A_e。出口面积A_e、流量和稳定工作范围未给，不能自行给出海平面推力，更不能在保持同一流量时随意保持Isp不变。[S7]

### 3.2 氧化剂与燃料的质量拆分

r_OF = m_LOX/m_CH4；  m_CH4 = m_p/(1+r_OF)

m_LOX = r_OF m_p/(1+r_OF)

若另行采用固定r_OF=3.4的假设，甲烷占总推进剂22.727%，液氧占77.273%。这是质量比例；不表示总推进剂质量已经求出，也不计混合比随工况变化。

### 4.1 先做近地推力可行性检查

按标准g₀做量级比较：干重为1.274865 MN，单台最大1.1 MN，干态推重比仅0.863；忽略近地阻力时，单台无法提供净向上减速度。两台最大2.2 MN，干态推重比约1.726，才具备进一步求解的必要条件。

两台最大推力对应静态支撑总质量约224.34 t（按g₀）；实际要用m(t)g(h)、倾斜推力、残余推进剂及控制余量检查。推力大于重量并不足以证明能及时制停或安全着陆。

### 4.2 人为探索网格（不作为可信上下界）

Isp取300/320/340 s；Cd取0.3/0.5/0.8/1.0；大气密度倍率取0.8/1.0/1.2。每个组合都是新的等效场景，不是某一实机的可实现性能点。跨声速阻力和逆向喷流影响仍需单独建模。

V0单台名义总推进剂流率为318.66 kg/s。这里只复算单位与量级，没有积分燃烧时长或给出燃料需求。

## 5 气动与气动热：有依据的形式，待定的系数

v_rel = v − w； q = ½ρ|v_rel|²； F_D = −q A_ref Cd v̂_rel

固定A_ref=πd²/4，并令Cd依赖Mach、Re、攻角和发动机状态。若改用侧投影面积，必须同时转换系数；不能将两个面积因子重复计入。[S8]

| 参数 / 项目 | 本版处理 | 依据与适用边界 |
| --- | --- | --- |
| Cd(M,Re,α,喷流状态) | U；0.5仅为H占位 | 没有匹配题中外形的完整曲线，[S8,S9] |
| 侧向力CN、气动力矩Cm | U；不可由Cd代替 | 姿态/操纵能力核查需要；首轮质点模型须说明省略 |
| 开机/关机气动差异 | 需分别定义/查表 | 逆向喷流会改变周围流场，[S9] |
| 气动动压 q | 按轨迹逐时计算 | q₀不是最大q；不为q_lim随意赋值 |
| 有效驻点曲率半径R_n | U；不默认等于3.5 m | 发动机底部、喷管和周边不是简单球头 |
| 热流代理系数k_SG | U；本版不赋数值 | 需气体/壁温/单位与适用条件，[S10] |
| 热防护上限与累积热量 | U；单独约束 | 材料、TPS与喷流加热/遮蔽数据均未给 |

### 5.1 文献能够支持什么

DLR的逆向喷流研究包含M=5.3和7.0的单/三发动机试验，并改变推力系数、Re与攻角，说明发动机开关及喷流条件不能仅靠一个恒定Cd处理。其外形和试验喷流与本题并不相同，不能直接复制系数。[S9]

### 5.2 热约束的初步表达

q̇_proxy ∝ √(ρ/R_n)|v_rel|³；  Q_proxy = ∫q̇_proxy dt

可借鉴Sutton–Graves驻点关联作趋势筛查，但本版只写比例关系，未算实际热流。它不能替代发动机朝前、逆向喷流和局部热防护的校核；若仍无材料限值，只能讨论条件性可行，不能写成热安全已证实。[S10]

## 6 初始条件、控制边界与安全限值

| 待定项 U | 论文/模型中的处理建议 |
| --- | --- |
| 分离航迹角γ₀与速度参考系 | 相对当地水平向上为正；初算按地面相对速度。γ₀可取0/15/30/45/60/90°作H情景；并非概率分布，负角可另加。 |
| 分离姿态与角速度 | 与航迹角不同；质点优化暂假设推力方向可跟随，随后需做姿态可实现性核查。 |
| 实际发动机数量与性能图 | 保留T、Isp、节流/重启能力参数；同一配置下完成轨迹求解。 |
| 点火延迟、耗剂与节流速率 | 定义可替换输入；后续有依据地加入，不以瞬时切换当成已验证实机能力。 |
| 重心、惯量和推力摆角 | 随推进剂消耗变化；不能只由65 m长度和干质量唯一决定。 |
| 动压/非重力载荷上限 | q_lim、n_lim参数化；n=|T+F_aero|/(m g₀)，不是坐标加速度除以g₀。 |
| 热流、热负荷与温度上限 | q̇_lim、Q_lim、T_lim待材料/TPS资料；无依据时不赋“安全”数值。 |
| 触地速度、倾角和角速度 | 按相对甲板量定义；理想目标可取零，允许容差须另行规定。 |
| 甲板高度、尺寸及运动 | 船位可选；每条候选轨迹中固定。静止、海平面甲板仅为H简化。 |
| 不可用残余与安全储备 | 理论分支可设残余为0（H）；工程分支分列残余、启动耗剂、控制/天气储备。 |

触地几何应以脚部接触甲板为事件。若状态位置采用质心，竖直时需满足h_CG=h_deck+l_CG–foot；不能让65 m长箭体的质心降到甲板再判定接触，也不能无依据地把该距离固定为32.5 m。

### 6.1 下一步优先级

①先固定或扫描γ₀；②选定一套自洽等效发动机族；③建立跨声速/喷流状态相关气动闭合；④按明确限值求可行下降轨迹；⑤再做误差扰动与储备，并把总推进剂拆分为液氧和甲烷。允许船位优化不等于不需要消除水平着陆速度。
