# 量级分析复算

Python 3；需要numpy、scipy、matplotlib以及Noto CJK字体。依赖环境具备时运行：

```bash
python scale_analysis.py
```

脚本按自身位置写入`../results/data/`、`../results/figures/`和`../results/logs/`，不修改v1/v2。

`atmosphere_1976.py`由v1同公式复制，仍仅开放几何高度0–70 km。70 km以上的真空弧线不调用大气；因此这不是对高层气动的外推或验证。实际有气动的高顶点返回必须另补高层大气。

`references/nominal_inputs_from_v2.json`记录参考参数来源。程序中的扫描质量、速度、风、力矩系数等诊断网格明确写在源码，不自动从实机数据推断。若修改输入或常数，需同步报告并重算。

源代码包括：冻结速度大气力尺度、无推力无气动中心重力弧线、火箭方程参照、定质量制停包络、末端/风/自转/热指标。两类图同时提供PNG与PDF，便于论文引用。缺Noto字体时修改脚本font_path为可用CJK字体路径。

已检查真空能量/角动量守恒、地表速率与能量式的一致性、步长加密；不证明现实着陆、气动标定或燃料需求。代码没有制导器、发动机调度优化器、姿态动力学、TPS或腿部接触模型。

原理图、器件/BOM、PCB、固件与旧电子模型均不受影响。比较基线见项目README。
