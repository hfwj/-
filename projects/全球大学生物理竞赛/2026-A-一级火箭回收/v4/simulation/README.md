# 审阅算术与静态几何复核

Python 3，仅标准库。在本目录运行：

```bash
python review_checks.py
```

生成发动机开机数比较、q_lim×n_lim的9格预算边界示例，以及静态轮廓与解析下缘检查。q/n表使用m=130 t、Cd=0.5、q=q_lim，只是边界算术，实际优化逐时使用q(t)/m(t)/完整气动力。

轮廓采用H几何：B为脚部中心；总高65 m，主筒s=2…65 m（低部2 m为腿净空），半径3.5 m，脚在s=0、r=±5 m。1 m网格128点，0.5 m网格254点，两侧直线并封端。

程序不作动态事件搜索；无连续时间无碰撞证明，也没有真实突出物轮廓、姿态、发动机调度或燃料优化。若题中65 m指主体长而不含支腿，应按报告改为s=2…67 m后同步修改程序和规范，不能直接沿用此算例。

不修改任何旧模型、原理图、器件/BOM、PCB或固件。
