# 无推力诊断与代数参照复算

Python 3，numpy、scipy。在本目录运行：

```bash
python passive_diagnostics.py
```

执行5组无推力常质量参考：真空130 t，以及空气下130/200 t×Cd=0.5/1。高度70 km、航迹角0°、初速1666.667 m/s，零风/无自转，至质心r=R_E终止；不是脚端触地、受控着陆或真实气动预测。

仅0–70 km作为正式输出域。RK与事件求根可能在边界外探测，同一层公式做平滑数值延拓，仅供内部阶段，不将其报告为飞行结果。代码没有推进剂状态或发动机指令；质量是各工况固定输入。

输出末速径向/切向分量、max-q、首次50 kPa状态、阻力功和角动量耗散平衡及步长细化记录。另求解常g、无阻力、恒T的一维变质量代数方程，仅用于检查质量/时长自洽，不是受控飞行积分。

`scale_analysis_v3_reference.py`及同名旧数据/图是v3量级资料的独立副本。运行该脚本需matplotlib和Noto字体；旧结果核查来源单独标为v3参考。运行任一脚本均只写本v5，不修改旧版本。

未实现受控正向模型、制导、姿态、TPS、着陆腿接触或最小燃料求解；此前停止的该项工作未恢复。硬件/原理图/BOM/PCB/固件与旧电子模型不变。
