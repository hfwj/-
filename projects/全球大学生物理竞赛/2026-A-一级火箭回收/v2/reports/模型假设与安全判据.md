# 2026 UPC A题：模型假设与安全判据

一级助推器海上回收 · v2 · 2026年11月7日

> 本版冻结一套可执行的论文参考方案。名义触地目标：脚端下降速度≤2 m/s、水平速度≤0.5 m/s、倾角≤2°。所有自定数值均标为H；热防护和接触后稳定性缺证据时保留“未核实”。本版是规范文档，尚未计算下降轨迹或燃料量。

### 1 已确定的基本假设

| --- | --- | --- |

| A02 | 初始速率1666.667 m/s，γ₀=0° | 速率来自题目；方向取水平为H，不默认为竖直向下。 |

| A04 | 分层标准大气；基准无风 | 仅代表参考环境；覆盖实际轨迹全域。 |
| A05 | 干质量130 t固定；推进剂变质量 | 不计晃动、柔性、泄漏和烧蚀。 |
| A11 | 静止水平甲板，海平面高度，二维半宽20 m | 船位在名义任务中优化一次，扰动时固定。 |

g(h)=GM_E/(R_E+h)²；  m(t)=m_d+m_unusable+m_use(t)

R_E=6 371 000 m，GM_E=3.986004418×10¹⁴ m³/s²。标准g₀=9.80665 m/s²用于比冲及无量纲载荷换算；它不替代动力学g(h)。空气参数及来源承接v1。[S1–S4]

### 1.1 两层模型各自承担什么

M0：二维质心平动＋推进剂质量，先求规划轨迹与用量。M1：在M0基础上核查箭体俯仰θ、角速度ω、力矩、执行器及着陆脚接触。未有M1时，姿态、脚端速度和接触后稳定性不得用“质点已减速”代替。

γ₀=15°/30°/45°/60°属于不同任务情景，可分别优化船位和控制。若轨迹高于70 km，现有v1大气脚本不足；必须扩展模型后再计算，高于约86 km另用适当高层大气。

T_i=u_i T_ref；  dm_use/dt=−Σ[T_i/(Isp_i g₀)]

常数等效推力忽略环境背压变化；不能把CNES历史1000 kN真空推力直接称为海平面值。320 s参考一级设计量级；360 s属于上面级方案。另固定氧燃质量比3.4（H）用于质量拆分。历史资料只支持量级，当前自定配置仍标H。[S6,S7]

### 2.1 不能被模型省略的影响

启动过渡按实际T曲线和等效Isp计入推进剂；额外无效启动耗剂暂不计，后续有数据时单列。姿态转换、气动力矩、栅格舵和关机时控制权限均未建成，不能在M1中静默设为零并宣称已校核。

Cd=0.5不代表跨声速真实曲线，也不代表发动机喷流作用已包含。最终论文至少比较不同Cd闭合、开/关机气动处理及任务方向；文献要求匹配Mach、Re、攻角和喷流条件。[S8,S9]

## 3 全程下降与制动判据

| 判据 | 本版名义目标 | 性质与解释 |
| --- | --- | --- |
| C01–C03 有效性 | 可用质量≥0；模型在域内；满足控制约束 | 必要条件；超域或无有效数值解标未核实。 |
| C04 最大动压 | q≤50 kPa | H；扫描30/50/70 kPa，不称实机结构额定。 |
| C05 非重力合加速度 | n_proper≤4 | H；非重力合力除以m g₀，自由落体取0。 |
| C06 力幅值预算 | n_Σ≤4 | H；限制各发动机推力幅值与气动力幅值之和。 |
| C07 高动压下降姿态 | v_r<0且q≥10 kPa时，α_b≤5° | H；发动机端迎风；必须有实际箭体姿态。 |
| C08 末段竖直化 | 最低脚部间隙≤200 m时，|θ|≤5° | H；200 m仅为姿态门槛，不是统一点火高度。 |

q=½ρ|v−w|²；  n_proper=|T_vec+F_aero|/(m g₀)

n_Σ=(Σ|T_i|+|F_aero|)/(m g₀)

n_proper不是|dv/dt|/g₀。推力和阻力可能相抵，故同时检查幅值预算n_Σ；后者仍不能覆盖实际内力、屈曲与弯矩。50 kPa在Cd=0.5时对应约0.962 MN阻力，只能说明量级，不能证明结构安全。

α_b=acos[e_b·(−v̂_rel)]，e_b由脚部中心指向箭体顶部；θ为e_b相对当地/甲板向上法线的倾角。低动压翻转需M1控制能力支持。无姿态状态时C07、C08为未核实，不自动通过。

### 3.1 点火前的可制停性筛查 C09

a_b=T_z,guaranteed/m_upper−g_max>0

h_req=wτ+½g_max τ²+(w+g_maxτ)²/(2a_b)+20 m

仅在已稳定近竖直时，取w为向下速度、τ为延迟及推力建立的保守等待时间、m_upper为制动中质量上界。要求h_clear≥h_req。基准从0到1.1的等待包络为0.5+1.1=1.6 s，可保守忽略建立期的部分推力；20 m为H余量。若推力受姿态、载荷或故障限制，必须相应下调T_z,guaranteed。此式不能替代变质量、受约束全轨迹求解，也不意味着只在200 m才点火。

## 4 首次触地判据：从着陆脚定义事件

在着陆点的局部水平x、向上z坐标中，甲板静止。令e_b=(sinθ, cosθ)、e_⊥=(cosθ,−sinθ)。二维两脚相对质心的位置与全局位置为：

r_±=−ℓe_b±b e_⊥；  p_±=p_CG+r_±；  p_B=p_CG−ℓe_b

h_clear=min(z_+,z_−)−h_deck；  首次 h_clear=0

B为两脚中心，ℓ=32.5 m、b=5 m均为H。首次接触取较低的脚，不要求两脚同时落地；θ≠0时以B高度等于甲板仍会漏掉先接触。竖直时质心高度应为h_deck+ℓ。

| 编号 | 名义触地标准（H） | 检查对象 |
| --- | --- | --- |
| C10 | 首个h_clear=0，事件定位误差≤0.01 m | 此前脚/箭体包络不穿甲板，脚外先碰撞不合格。 |
| C11 | −2≤v_rel,z≤0 m/s | 所有当前接触脚；理想控制仍瞄准0。 |
| C12 | |v_rel,x|≤0.5 m/s | 所有当前接触脚，相对甲板。 |
| C13 | |x_B−x_ship|≤5 m | 脚部中心相对选定目标，不是自由改船位。 |
| C13 | 全部脚|x_foot−x_ship|≤18 m | 20 m甲板半宽扣除2 m边缘余量。 |
| C14 / C15 | |θ|≤2°；|ω|≤0.5°/s | 实际箭体相对甲板姿态与角速度。 |

v_±=v_CG+ω(−ℓe_⊥∓b e_b)；  v_rel,±=v_±−v_deck

ω=dθ/dt，代入速度式时用rad/s。只检查质心速度会漏掉脚端的转动速度；M0没有θ、ω时不能用推力方向或摆速代替它们。以上为首次软触地目标，接触后是否稳住还要检查C18。

### 4.1 数值目标的物理解释

仅用干质量估算，2 m/s竖直触地动能为260 kJ。若另假设0.5 m吸能行程，恒定减速所需平均接触力约为重量的1.408倍；真实含残余推进剂的动能更高，峰值力和偏载也未计入。因此2 m/s是设计目标，不能据此宣称未知着陆腿足够。

## 5 燃料储备、结构热核查与最终稳定

### 5.1 储备规则 A13 / C16

m_unusable=0.005 m_p,0；  m_use(0)=0.995 m_p,0

m_res=T_land,max·1 s/(Isp g₀)=701.05 kg

名义轨迹要求m_use(t_td)≥m_res，全程m_use≥0。2.2 MN为两台虚拟发动机的最大合推力；1 s储备和0.5%不可用残余均是H，不是行业统一规定。二者都保留在质量中，会影响制动。储备不等于直接给计算耗量乘1.01或1.10。

后续求m_p,0时，同时积分实际推力的耗剂；不可用残余不可被发动机消耗。扰动回放可动用701.05 kg应急储备，但仍不得出现可用量为负。若控制改善后无需动用，应如实报告剩余量。

| 结构强度/稳定性 | 材料、截面、连接、压力与推力/气动组合内力；应力、屈曲和弯矩限值 | U；q与n_Σ筛查通过后仍为未核实。 |
| 热流/累积热负荷 | 适用的局部热模型；材料/TPS允许热流、累计热量和壁温 | U；仅有热代理曲线时不能判热安全通过。 |

| 执行器与气动力矩 | 摆角/力矩权限、惯量、重心、姿态回放 | U；理想跟随假设不能替代实际姿态可行。 |

Sutton–Graves可作为钝体驻点热趋势参考，但有效曲率、壁面和喷流条件未闭合；不得自动令驻点半径=3.5 m，也不从它直接推出本火箭TPS温度上限。[S9,S10]

### 5.3 接触后稳定 C18

另设至少2 s稳定支撑检查窗口（H）：无倾覆/滑移，接触支撑力、腿行程和吸能在能力内，燃机关停不破坏稳定。理想二维静态倾覆角约atan(b/ℓ)=8.75°，但这不覆盖冲击、风、姿态速率或摩擦。若模型止于首次接触，C18须标未核实；不能将“首次触地合格”直接写成“已稳定着陆”。

## 6 扰动检验与判定规则

以下取点均为H，用于展示脆弱性，不代表真实概率、置信区间或连续不确定集的严格最坏界。先完成名义轨迹，再把同一船位、初始储备和同一控制策略用于扰动回放。

| 扰动项 | 建议试验取点 | 要求 |
| --- | --- | --- |
| 密度/压强倍率 | k_ρ=0.8 / 1.0 / 1.2 | T不变时p和ρ同时缩放，保留理想气体关系。 |
| 水平风 | w₀=−10 / 0 / +10 m/s | w(h)=w₀ max(0,1−h/20 km)，沿当地水平。 |
| 发动机效率与推力 | T倍率0.9 / 1.0；Isp=304 / 320 s | 等效不利扰动；不冒充某实机相关性能图。 |
| 点火响应 | 延迟0.5 / 1.0 s；节流速率不放宽 | 重算制停包络与全程约束。 |
| 气动闭合 | Cd=0.3 / 0.5 / 0.8 / 1.0 | 统一参考面积；另比较Mach/喷流状态相关曲线。 |
| 初始状态偏差 | h₀±100 m、V₀±1%、γ₀±2° | 这是名义任务的小扰动；异航迹角任务另列。 |
| 末端几何 | ℓ=26/32.5/39 m；b=4/5/6 m | 终端几何敏感性；不宣称已覆盖质量分布演化。 |
| 储备与阈值选择 | 储备0/1/2 s；q_lim=30/50/70 kPa；n_Σ=3/4/5 | 属于设计标准对比，可各自重优化，不能冒充固定设计的鲁棒性。 |

先做单项再做组合角点试验；角点均通过也不是连续不确定集的数学保证。若每个扰动都重新寻找最优控制，得到的是“可重规划能力”，不等于原方案抗扰性。开环控制必须沿用同一时序；闭环控制可根据状态响应，但控制律及其参数保持固定。

### 6.1 三态判定，先处理缺证据

FAIL：至少一项已计算的必检条件越限。NOT_VERIFIED：没有越限证据，但缺有效轨迹、状态、模型、材料限值或数值可靠性。PASS：指定层级内的所有必检项有证据且全部满足；只能写为“在本文模型与假设下通过”。求解失败不自动等于物理不可行。

### 6.2 数值合格目标（H）

采用接触事件根定位，间隙误差≤0.01 m；加密积分步长/优化网格后，m_p,0变化≤0.5%，触地速度变化≤0.02 m/s且所有约束仍满足。最大动压与载荷用加密回放检查峰值，不能只看离散节点。阈值附近且误差不能排除越限时标未核实。

## 7 可直接改写进论文的表述

### 7.1 “模型假设”段落

> 将助推器返回过程近似为球形地球大圆竖直平面内的变质量运动，重力随高度变化，环境采用覆盖全部轨迹高度的分层标准大气。忽略地球自转、侧向运动、基准风场、结构弹性和推进剂晃动。题目给出的分离速率解释为地面相对速率；因未给速度方向，参考工况取相对当地水平航迹角0°，其余航迹角作为独立情景讨论。

推进系统采用明确标注的虚拟液氧/甲烷等效发动机族：安装3台，单台名义推力1 MN、比冲320 s，稳态节流30%–110%；着陆末次燃烧使用2台，启动及节流变化受到有限响应约束。以上是本文建模假设，不代表题目指定了某种实机。船位在名义方案设计中选择一次，此后固定；甲板在二维模型中视为静止水平面。

### 7.2 “安全判据”段落

> 本文将安全要求分为轨迹/控制有效性、软触地目标、结构热核查和接触后稳定四类。作为名义设计标准，最大动压限制为50 kPa，非重力合加速度和各力幅值预算均不超过4倍标准重力/重量的相应无量纲指标。首次接触时，各接触脚相对甲板的下降速度不超过2 m/s、水平速度不超过0.5 m/s，箭体倾角不超过2°、角速度不超过0.5°/s，且脚部中心距目标不超过5 m、各脚保留至少2 m甲板边缘余量。

上述阈值由本文选定，并通过阈值变化与扰动回放检验结论敏感性；它们不是制造商额定安全包线。结构、热防护、姿态执行器及接触后稳定性仅在对应模型和限值具备时判定通过，缺证据时报告未核实。名义轨迹还保留相当于1 s最大着陆推力耗剂的可用储备，不可用残余另行计入质量。
